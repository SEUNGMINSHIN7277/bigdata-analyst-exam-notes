### Q4-019 [난이도: 하] [태그: 4과목/분석모형평가및개선/과대적합]

어떤 분류 모형이 훈련 데이터에서는 정확도 98%를 기록했지만, 별도의 평가 데이터에서는 정확도가 70%에 그쳤다. 이 모형이 보이는 현상은?

① 과소적합(underfitting)
② 과대적합(overfitting)
③ 기울기 소실(gradient vanishing)
④ 차원의 저주(curse of dimensionality)

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** 과소적합은 모형이 너무 단순해 **훈련 데이터에서조차 성능이 낮은** 현상. 훈련 98%와 모순.
- **②** 훈련 데이터에만 지나치게 맞춰져 새 데이터(평가)에서 성능이 급락 → 과대적합. ← 정답
- **③** 기울기 소실은 역전파 시 기울기가 0에 가까워져 **학습 자체가 안 되는** 신경망 학습 문제. 성능 격차 현상이 아님.
- **④** 차원의 저주는 변수(차원)가 늘수록 데이터가 희소해져 분석이 어려워지는 문제. 훈련·평가 성능 격차의 직접 명칭이 아님.

**출제 포인트:** "훈련↑ 평가↓ = 과대적합, 훈련↓ 평가↓ = 과소적합"으로 즉시 판별. 두 성능의 **격차**가 크면 과대적합이다.

**근거:** 과대적합(overfitting)은 모형이 훈련 데이터의 잡음까지 학습하여 훈련 데이터 성능은 높지만 새로운 데이터에 대한 일반화 성능이 떨어지는 현상이다.
</details>

### Q4-020 [난이도: 하] [태그: 4과목/분석모형평가및개선/L1규제]

회귀 계수의 절댓값 합을 벌점(penalty)으로 부과하여 일부 계수를 정확히 0으로 만들고, 이를 통해 변수 선택 효과를 갖는 규제 기법은?

① L1 규제(라쏘, Lasso)
② L2 규제(릿지, Ridge)
③ 드롭아웃(dropout)
④ 조기 종료(early stopping)

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** 절댓값 합(|w|) 벌점 → 일부 계수가 정확히 0 → 희소성(sparsity)·변수 선택 효과 → L1 규제(라쏘). ← 정답
- **②** L2 규제(릿지)는 **제곱합** 벌점으로 계수를 0에 가깝게 **축소**만 할 뿐, 정확히 0으로 만들지 않는다.
- **③** 드롭아웃은 신경망 학습 시 뉴런을 무작위로 제외하는 기법. 회귀 계수 벌점과 무관.
- **④** 조기 종료는 검증 성능이 나빠지기 전에 학습을 멈추는 기법. 벌점 부과 방식이 아님.

**출제 포인트:** L1 = 절댓값·계수 0·희소·변수 선택(라쏘) / L2 = 제곱·계수 축소·0은 안 됨(릿지). "절댓값→라쏘, 제곱→릿지"로 암기.

**근거:** L1 규제(라쏘)는 회귀 계수의 절댓값 합을 벌점으로 부과해 일부 계수를 정확히 0으로 만들어 변수 선택 효과를 갖는 규제 기법이다.
</details>

### Q4-021 [난이도: 하] [태그: 4과목/분석모형평가및개선/드롭아웃]

신경망 학습 과정에서 매 반복(iteration)마다 일부 뉴런(노드)을 무작위로 제외하고 학습시켜 과대적합을 방지하는 기법은?

① 배치 정규화(batch normalization)
② 조기 종료(early stopping)
③ 드롭아웃(dropout)
④ 데이터 증강(data augmentation)

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 배치 정규화는 미니배치 단위로 층의 입력을 **정규화**하는 기법. 뉴런 제외가 아님.
- **②** 조기 종료는 검증 오차가 증가하기 시작하면 **학습을 중단**하는 기법. 뉴런 제외가 아님.
- **③** 학습 시 뉴런을 확률적으로 꺼서(제외) 특정 뉴런 의존을 막는 과대적합 방지 기법 → 드롭아웃. ← 정답
- **④** 데이터 증강은 원본 데이터를 변형해 **훈련 데이터 양을 늘리는** 기법. 뉴런 제외가 아님.

**출제 포인트:** "뉴런 무작위 제외 = 드롭아웃". 단, 드롭아웃은 **학습 시에만** 적용하고 예측(추론) 시에는 모든 뉴런을 사용한다는 점이 함정 선지로 출제된다.

**근거:** 드롭아웃(dropout)은 신경망 학습 시 일부 뉴런을 무작위로 제외하여 특정 뉴런에 대한 의존을 줄임으로써 과대적합을 방지하는 기법이다.
</details>

### Q4-022 [난이도: 하] [태그: 4과목/분석모형평가및개선/하이퍼파라미터]

다음 중 사용자가 설정하는 하이퍼파라미터(hyperparameter)가 아니라, 모형이 학습을 통해 스스로 결정하는 파라미터(parameter)에 해당하는 것은?

① 학습률(learning rate)
② 에폭(epoch) 수
③ 은닉층(hidden layer)의 수
④ 가중치(weight)와 편향(bias)

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 학습률은 학습 전에 사람이 정하는 값 → 하이퍼파라미터.
- **②** 에폭 수(전체 데이터 반복 학습 횟수)는 사람이 정하는 값 → 하이퍼파라미터.
- **③** 은닉층 수(모형 구조)는 사람이 정하는 값 → 하이퍼파라미터.
- **④** 가중치·편향은 학습 과정에서 데이터로부터 **자동으로 추정**되는 값 → 파라미터. ← 정답

**출제 포인트:** "사람이 정하면 하이퍼파라미터(학습률·에폭·배치 크기·은닉층 수·규제 강도), 학습이 정하면 파라미터(가중치·편향·회귀 계수)". 가중치를 하이퍼파라미터로 두는 선지가 단골 함정.

**근거:** 파라미터는 모형이 학습을 통해 데이터로부터 추정하는 값(가중치·편향)이고, 하이퍼파라미터는 학습 전에 사용자가 설정하는 값(학습률·에폭·배치 크기 등)이다.
</details>

### Q4-023 [난이도: 중] [태그: 4과목/분석모형평가및개선/과대적합해결]

과대적합(overfitting)을 완화하기 위한 방법으로 적절하지 <u>않은</u> 것은?

① 은닉층과 노드 수를 늘려 모형의 복잡도를 높인다.
② 원본 데이터를 변형·확장하는 데이터 증강(data augmentation)으로 훈련 데이터를 늘린다.
③ L1·L2 규제(regularization)를 적용해 가중치가 과도하게 커지지 않도록 한다.
④ 검증 오차가 증가하기 시작하면 학습을 멈추는 조기 종료(early stopping)를 적용한다.

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** 복잡도를 **높이면** 훈련 데이터에 더 밀착되어 과대적합이 **심해진다**. 과대적합에는 모형 단순화가 해결책이고, 복잡도 증가는 **과소적합**의 해결책. ← 정답
- **②** 적절. 훈련 데이터가 많아지면 잡음에 덜 민감해져 일반화 성능이 좋아진다.
- **③** 적절. 규제는 가중치 크기에 벌점을 주어 모형을 단순하게 유지한다.
- **④** 적절. 검증 오차가 나빠지기 전에 멈춰 과도한 학습을 차단한다.

**출제 포인트:** 과대적합 해결 = 데이터 증강 / 모형 단순화 / 규제 / 드롭아웃 / 조기 종료. 과소적합 해결 = 모형 복잡화 / 변수 추가 / 학습 횟수 증가. 두 처방을 바꿔치기한 선지가 정답이 되는 패턴.

**근거:** 과대적합의 대표적 완화 방법은 훈련 데이터 확대(데이터 증강), 모형 단순화, 규제 적용, 드롭아웃, 조기 종료이다.
</details>

### Q4-024 [난이도: 중] [태그: 4과목/분석모형평가및개선/경사하강법]

경사하강법(gradient descent)의 세 가지 방식에 대한 설명으로 옳은 것은?

① 배치 경사하강법(batch GD)은 매 갱신마다 데이터 1건만 사용하므로 계산이 가장 빠르다.
② 확률적 경사하강법(SGD)은 전체 데이터를 모두 사용하므로 갱신 방향이 가장 안정적이다.
③ 미니배치 경사하강법(mini-batch GD)은 전체와 1건의 절충으로, 일정 크기의 묶음 단위로 갱신한다.
④ 확률적 경사하강법(SGD)은 배치 경사하강법보다 항상 안정적으로 수렴한다.

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 배치 경사하강법은 **전체 데이터**로 기울기를 계산해 1회 갱신. "1건만 사용"은 SGD의 설명.
- **②** SGD는 **1건(또는 소수)** 씩 사용해 빠르지만 갱신 방향이 **불안정(진동)**. "전체 사용·안정"은 배치의 설명.
- **③** 미니배치는 전체(배치)와 1건(SGD)의 절충으로, 일정 크기 묶음(예: 32, 64건)마다 갱신 → 속도와 안정성의 균형. ← 정답
- **④** SGD는 빠르지만 진동이 커서 **불안정**하다. "항상 안정적"은 틀린 설명.

**출제 포인트:** 배치 = 전체·안정·느림 / SGD = 1건·빠름·불안정 / 미니배치 = 묶음·절충(실무 표준). "사용 데이터 양"과 "안정성"을 서로 바꿔치기한 선지를 주의.

**근거:** 경사하강법은 1회 갱신에 사용하는 데이터 양에 따라 배치(전체), 확률적(1건), 미니배치(일정 크기 묶음) 방식으로 구분된다.
</details>

### Q4-025 [난이도: 중] [태그: 4과목/분석모형평가및개선/옵티마이저]

다음 설명에 해당하는 옵티마이저(optimizer)는?

> 이전 갱신에서 이동하던 방향을 관성(inertia)처럼 현재 갱신에 반영하여, 진동을 줄이고 지역 최소값(local minimum)을 지나칠 수 있도록 돕는다.

① AdaGrad
② 모멘텀(Momentum)
③ RMSProp
④ Adam

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** AdaGrad는 변수별로 **학습률을 조정**하는 방식(기울기 누적이 클수록 학습률 감소). 관성 개념이 아님.
- **②** "이전 이동 방향을 관성처럼 반영" → 모멘텀. ← 정답
- **③** RMSProp은 AdaGrad의 학습률 누적 감소 문제를 지수이동평균으로 **보완**한 방식. 관성 개념이 아님.
- **④** Adam은 모멘텀 + RMSProp을 **결합**한 방식. 관성만을 설명한 지문보다 범위가 넓다.

**출제 포인트:** 매칭 키워드 — 모멘텀 = "관성·이전 방향" / AdaGrad = "학습률 누적 감소" / RMSProp = "AdaGrad 보완·지수이동평균" / Adam = "모멘텀+RMSProp 결합".

**근거:** 모멘텀(Momentum)은 이전 갱신의 이동 방향을 관성으로 반영하여 경사하강법의 진동을 줄이고 수렴을 가속하는 옵티마이저다.
</details>

### Q4-026 [난이도: 중] [태그: 4과목/분석모형평가및개선/기울기소실]

심층 신경망의 역전파(backpropagation) 과정에서 출력층에서 입력층 방향으로 갈수록 기울기가 0에 가까워져 앞쪽 층의 가중치가 거의 갱신되지 않는 문제와, 이를 완화하기 위해 은닉층에 널리 사용되는 활성화 함수를 옳게 짝지은 것은?

① 기울기 소실(gradient vanishing) — ReLU
② 기울기 소실(gradient vanishing) — 시그모이드(sigmoid)
③ 과대적합(overfitting) — ReLU
④ 기울기 폭주(gradient exploding) — 시그모이드(sigmoid)

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** "역전파 시 기울기가 0에 수렴 → 앞쪽 층 학습 정지" = 기울기 소실. ReLU는 양수 입력 구간에서 기울기가 1로 유지되어 소실을 완화한다. ← 정답
- **②** 문제 명칭은 맞지만, 시그모이드는 도함수의 최댓값이 작아(최대 0.25) 층을 거칠수록 기울기가 급격히 작아지는 **소실의 원인**이지 해결책이 아니다.
- **③** 과대적합은 훈련 데이터에는 잘 맞고 새 데이터에서 성능이 떨어지는 **일반화 문제**로, 역전파 기울기 현상과 다른 개념이다.
- **④** 기울기 폭주는 기울기가 비정상적으로 **커져** 학습이 발산하는 문제로, 지문의 "0에 가까워지는" 현상과 반대이며 시그모이드가 해결책도 아니다.

**출제 포인트:** 매칭 공식 — "기울기가 0에 수렴 = 소실 → ReLU로 완화" / "기울기가 폭발적으로 증가 = 폭주". 시그모이드·tanh를 해결책 자리에 놓는 원인↔해결 바꿔치기 선지가 단골 함정.

**근거:** 기울기 소실(gradient vanishing)은 심층 신경망의 역전파 시 기울기가 층을 거치며 0에 가까워져 입력층 부근 가중치가 학습되지 않는 문제로, 양수 구간에서 기울기 1을 유지하는 ReLU 활성화 함수가 대표적인 완화 방법이다.
</details>

### Q4-027 [난이도: 중] [태그: 4과목/분석모형평가및개선/학습률]

경사하강법의 학습률(learning rate)에 대한 설명으로 옳지 <u>않은</u> 것은?

① 학습률이 지나치게 크면 최적값을 지나쳐 진동하거나 발산할 수 있다.
② 학습률이 지나치게 작으면 수렴 속도가 매우 느려지고 지역 최소값에 머무를 수 있다.
③ 학습률은 학습 전에 사용자가 설정하는 하이퍼파라미터다.
④ 학습률은 클수록 항상 더 정확한 최적해에 도달한다.

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 옳은 설명. 과대 학습률 → 보폭이 커서 최소점을 계속 지나침 → 진동·발산.
- **②** 옳은 설명. 과소 학습률 → 보폭이 작아 학습이 느리고 지역 최소값 탈출이 어렵다.
- **③** 옳은 설명. 학습률은 사람이 정하는 대표적 하이퍼파라미터.
- **④** 학습률이 크면 발산 위험이 커진다. "클수록 항상 정확"은 틀린 설명 → 적절한 크기 설정이 핵심. ← 정답

**출제 포인트:** 학습률 과대 = 발산·진동, 학습률 과소 = 느린 수렴·지역해. "항상", "무조건"이 들어간 선지는 함정일 확률이 높다.

**근거:** 학습률은 경사하강법에서 가중치를 한 번에 갱신하는 보폭을 결정하는 하이퍼파라미터로, 과대하면 발산하고 과소하면 수렴이 느려진다.
</details>

### Q4-028 [난이도: 중] [태그: 4과목/분석모형평가및개선/하이퍼파라미터튜닝]

하이퍼파라미터 탐색 기법인 그리드 서치(grid search)와 랜덤 서치(random search)에 대한 설명으로 옳지 <u>않은</u> 것은?

① 그리드 서치는 사용자가 지정한 후보 값들의 모든 조합을 빠짐없이 탐색한다.
② 랜덤 서치는 지정된 범위 안에서 하이퍼파라미터 값을 무작위로 추출해 탐색한다.
③ 그리드 서치는 하이퍼파라미터의 종류와 후보 값이 늘어나도 탐색해야 할 조합의 수가 증가하지 않는다.
④ 랜덤 서치는 탐색 공간이 넓을 때 그리드 서치보다 효율적일 수 있다.

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 옳은 설명. 그리드 서치는 격자(grid)의 전 조합을 전수 탐색한다.
- **②** 옳은 설명. 랜덤 서치는 정해진 횟수만큼 무작위 표본을 추출해 시험한다.
- **③** 그리드 서치의 조합 수는 후보 값 수의 **곱**으로 늘어난다(예: 3종 × 각 4개 후보 = 4×4×4 = 64조합). 종류·후보가 늘수록 **기하급수적으로 증가**하는 것이 그리드 서치의 한계. ← 정답
- **④** 옳은 설명. 랜덤 서치는 시도 횟수를 고정할 수 있어 넓은 공간에서 효율적일 수 있다.

**출제 포인트:** 그리드 = 전 조합·정확하지만 조합 폭발 / 랜덤 = 무작위 추출·빠르지만 최적 보장 없음. "조합 수가 늘지 않는다"류의 상식 반전 선지가 정답 패턴.

**근거:** 그리드 서치는 지정한 하이퍼파라미터 후보 값의 모든 조합을 전수 탐색하는 기법이고, 랜덤 서치는 지정 범위에서 무작위로 추출한 조합만 탐색하는 기법이다.
</details>

### Q4-029 [난이도: 중] [태그: 4과목/분석모형평가및개선/배치정규화조기종료]

배치 정규화(batch normalization)와 조기 종료(early stopping)에 대한 설명으로 옳지 <u>않은</u> 것은?

① 배치 정규화는 미니배치 단위로 층의 입력 분포를 정규화하여 학습을 안정화한다.
② 조기 종료는 훈련 오차가 증가하기 시작하는 시점에 학습을 중단하는 기법이다.
③ 배치 정규화는 층을 지날 때마다 입력 분포가 변하는 문제를 완화해 학습 속도를 높인다.
④ 조기 종료는 불필요하게 오래 학습하여 발생하는 과대적합을 방지한다.

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** 옳은 설명. 미니배치의 평균·분산으로 입력을 정규화해 학습을 안정화한다.
- **②** 조기 종료의 중단 기준은 **검증(validation) 오차**다. 훈련 오차는 학습을 계속하면 대개 계속 감소하므로 기준이 될 수 없다. ← 정답
- **③** 옳은 설명. 내부 공변량 변화(internal covariate shift)를 완화해 높은 학습률 사용과 빠른 학습을 가능하게 한다.
- **④** 옳은 설명. 검증 성능이 나빠지기 전에 멈추므로 과대적합 방지 기법으로 분류된다.

**출제 포인트:** 조기 종료의 기준은 "훈련 오차"가 아니라 "**검증 오차** 증가 시점". 훈련↔검증 바꿔치기가 이 유형의 핵심 함정.

**근거:** 조기 종료(early stopping)는 학습 중 검증 오차가 증가하기 시작하는 시점에 학습을 중단하여 과대적합을 방지하는 기법이다.
</details>

### Q4-030 [난이도: 상] [태그: 4과목/분석모형평가및개선/규제비교]

규제(regularization) 기법에 대한 설명으로 옳지 <u>않은</u> 것은?

① 라쏘(Lasso)는 L1 벌점을 사용하여 희소(sparse)한 모형을 만든다.
② 릿지(Ridge)는 계수를 0에 가깝게 축소하지만 정확히 0으로 만들지는 않는다.
③ 엘라스틱넷(Elastic Net)은 L1과 L2 벌점을 함께 사용하는 절충 기법이다.
④ L2 규제는 일부 계수를 정확히 0으로 만들기 때문에 변수 선택 목적으로 주로 사용된다.

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 옳은 설명. L1(절댓값 합) 벌점은 다수의 계수를 0으로 만들어 희소 모형을 생성한다.
- **②** 옳은 설명. L2(제곱합) 벌점은 계수를 골고루 축소(shrinkage)할 뿐 0으로 만들지 않는다.
- **③** 옳은 설명. 엘라스틱넷 = L1 + L2 결합, 두 규제의 절충.
- **④** "계수를 정확히 0으로 만들어 변수 선택"은 **L1(라쏘)** 의 특징이다. L2는 축소만 한다. ← 정답

**출제 포인트:** L1 = 0으로 만듦·변수 선택·희소성(라쏘) / L2 = 축소만·다중공선성에 강건(릿지) / L1+L2 = 엘라스틱넷. 두 규제의 특징을 맞바꾼 선지가 상급 문제의 정답 패턴.

**근거:** L2 규제(릿지)는 계수의 제곱합을 벌점으로 부과해 계수를 0에 가깝게 축소하되 0으로 만들지는 않는 규제 기법으로, 변수 선택 효과는 L1 규제(라쏘)의 특징이다.
</details>

### Q4-031 [난이도: 상] [태그: 4과목/분석모형평가및개선/옵티마이저계보]

옵티마이저(optimizer)의 발전 과정에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. 모멘텀(Momentum)은 이전 이동 방향을 관성으로 반영해 갱신의 진동을 줄인다.
- ㄴ. AdaGrad는 기울기 제곱을 계속 누적하므로 학습이 진행될수록 학습률이 감소해 0에 가까워지는 문제가 있다.
- ㄷ. RMSProp은 지수이동평균을 사용하여 AdaGrad의 학습률 소실 문제를 보완했다.
- ㄹ. Adam은 AdaGrad와 배치 정규화(batch normalization)를 결합한 방식이다.

① ㄱ, ㄴ, ㄷ  ② ㄱ, ㄹ  ③ ㄴ, ㄷ, ㄹ  ④ ㄱ, ㄴ, ㄷ, ㄹ

<details><summary>정답 및 해설</summary>

**정답: ①**

- **ㄱ (O)** 모멘텀 = 관성으로 진동 완화·수렴 가속.
- **ㄴ (O)** AdaGrad = 기울기 제곱 누적으로 변수별 학습률 조정, 누적이 커질수록 학습률이 0에 가까워져 학습이 멈추는 한계.
- **ㄷ (O)** RMSProp = 누적 대신 지수이동평균(최근 기울기에 가중)으로 AdaGrad의 소실 문제 보완.
- **ㄹ (X)** Adam = **모멘텀 + RMSProp**의 결합이다. 배치 정규화는 옵티마이저가 아니라 학습 안정화 기법.

따라서 옳은 것은 ㄱ, ㄴ, ㄷ → **①**. (②·④는 틀린 ㄹ 포함 여부와 옳은 항목 누락, ③은 틀린 ㄹ을 포함)

**출제 포인트:** 계보 흐름 — GD → 모멘텀(관성 개선) / AdaGrad(학습률 개선) → RMSProp(AdaGrad 보완) → Adam(모멘텀+RMSProp). Adam의 결합 대상을 바꿔치기(AdaGrad, 배치 정규화 등)한 선지가 단골.

**근거:** 옵티마이저는 관성을 도입한 모멘텀과 학습률을 적응 조정하는 AdaGrad, 이를 보완한 RMSProp을 거쳐 두 계열을 결합한 Adam으로 발전했다.
</details>

### Q4-032 [난이도: 상] [태그: 4과목/분석모형평가및개선/최종모형선정]

분석모형 융합과 최종모형 선정에 대한 설명으로 옳은 것은?

① 최종모형은 훈련 데이터에서의 성능이 가장 높은 모형으로 선정하면 충분하다.
② 여러 모형을 융합(앙상블)하면 단일 모형보다 예측 결과의 해석이 항상 쉬워진다.
③ 최종모형 선정 시 평가 데이터의 성능 지표와 함께 해석 가능성, 운영 환경 적용 가능성 등 비즈니스 요건을 종합적으로 고려한다.
④ 보팅(voting)은 여러 모형의 예측을 결합하는 방법이 아니라 하나의 모형을 반복 학습시키는 방법이다.

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 훈련 성능만 보면 과대적합 모형을 선정할 위험이 있다. 선정 기준은 **평가(검증) 데이터의 일반화 성능**.
- **②** 앙상블은 성능은 좋아질 수 있으나 여러 모형이 결합되어 **해석은 오히려 어려워지는** 경향이 있다. "항상 쉬워진다"는 틀림.
- **③** 성능 지표 + 해석 가능성 + 운영 적용성(속도·비용·유지보수) + 비즈니스 목표 부합을 종합 고려하는 것이 최종모형 선정의 원칙. ← 정답
- **④** 보팅은 서로 다른 여러 모형의 예측을 **다수결·평균으로 결합**하는 융합 방법이다. "반복 학습"은 부스팅 계열에 가까운 설명.

**출제 포인트:** 최종모형 선정 3요소 — **평가 데이터 성능 / 해석 가능성 / 운영(비즈니스) 적용성**. "훈련 성능만", "항상"이 들어간 선지는 함정.

**근거:** 최종모형 선정은 평가 데이터 기반 성능 지표에 해석 가능성과 운영 환경 적용 가능성 등 비즈니스 요건을 더해 종합적으로 판단하는 과정이다.
</details>
