### Q4-041 [난이도: 하] [태그: 4과목/분석결과해석및활용/시간시각화]

시간의 흐름에 따른 데이터의 변화·추세(trend)를 표현하는 시간 시각화 기법에 해당하는 것은?

① 파이 차트(pie chart)
② 선 그래프(line graph)
③ 산점도(scatter plot)
④ 히트맵(heatmap)

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** 전체에서 각 부분이 차지하는 비율을 표현 → 분포 시각화.
- **②** 시간 축을 따라 값의 변화·추세를 표현 → 시간 시각화. ← 정답
- **③** 두 변수 간의 관계를 점으로 표현 → 관계 시각화.
- **④** 값의 크기를 색상으로 표현해 여러 항목을 비교 → 비교 시각화.

**출제 포인트:** 시간 시각화 = 막대그래프·선그래프·영역 차트·계단식 그래프. "추세·시계열"이 보이면 시간 시각화로 연결.

**근거:** 시간 시각화는 시간의 흐름에 따른 데이터의 변화와 경향(추세)을 표현하는 시각화 유형으로 막대그래프·선그래프·영역 차트·계단식 그래프가 대표적이다.
</details>

### Q4-042 [난이도: 하] [태그: 4과목/분석결과해석및활용/카토그램]

지역별 데이터 값(인구, 선거인 수 등)에 비례하도록 지도의 면적을 의도적으로 왜곡하여 표현하는 공간 시각화 기법은?

① 도트맵(dot map)
② 등치지역도(choropleth map)
③ 버블 플롯맵(bubble plot map)
④ 카토그램(cartogram)

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 지도 위에 데이터 값을 같은 크기의 점의 개수·밀도로 표현. 면적 왜곡 없음.
- **②** 지역별 값을 색상의 음영·농도로 구분해 표현. 면적은 실제 지도 그대로.
- **③** 지도 위 해당 위치에 원(버블)의 크기로 값을 표현. 면적 왜곡 없음.
- **④** 값에 비례해 지역의 면적 자체를 확대·축소(왜곡)해 그린 변형 지도. ← 정답

**출제 포인트:** 공간 시각화 구분 키워드 — 색상 농도=등치지역도, 점의 밀도=도트맵, 원의 크기=버블 플롯맵, **면적 왜곡=카토그램**.

**근거:** 카토그램(cartogram)은 특정 데이터 값에 비례하여 지역의 면적을 의도적으로 왜곡해 표현하는 변형 지도 형태의 공간 시각화 기법이다.
</details>

### Q4-043 [난이도: 하] [태그: 4과목/분석결과해석및활용/분포시각화]

다음 중 분포 시각화 기법에 해당하지 <u>않는</u> 것은?

① 산점도(scatter plot)
② 파이 차트(pie chart)
③ 도넛 차트(donut chart)
④ 트리맵(treemap)

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** 두 변수 간 상관관계를 점으로 표현 → 관계 시각화. 분포 시각화가 아님. ← 정답
- **②** 원 전체를 100%로 두고 부분의 비율을 부채꼴로 표현 → 분포 시각화.
- **③** 파이 차트의 가운데를 비운 형태로 비율을 표현 → 분포 시각화.
- **④** 전체를 사각형 영역으로 나누고 면적으로 비율·계층을 표현 → 분포 시각화.

**출제 포인트:** 분포 시각화 = 파이·도넛·트리맵·누적 영역 차트. "전체 대비 비율·구성"이 핵심 키워드.

**근거:** 분포 시각화는 전체에서 각 부분이 차지하는 비율이나 분류를 표현하는 시각화 유형으로 파이 차트·도넛 차트·트리맵·누적 영역 차트가 대표적이다.
</details>

### Q4-044 [난이도: 하] [태그: 4과목/분석결과해석및활용/체르노프페이스]

다변량 데이터를 눈·코·입·귀 등 사람 얼굴의 각 요소에 대응시켜, 얼굴 모양의 차이로 여러 대상을 비교하는 시각화 기법은?

① 스타 차트(star chart)
② 평행 좌표 그래프(parallel coordinates)
③ 체르노프 페이스(Chernoff faces)
④ 히트맵(heatmap)

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 중심에서 뻗은 방사형 축에 변수 값을 표시해 다각형으로 비교. 얼굴 요소와 무관.
- **②** 여러 개의 평행한 세로 축에 변수를 배치하고 선으로 연결해 다변량을 비교. 얼굴 요소와 무관.
- **③** 변수 값을 얼굴 요소(눈 크기, 입 모양 등)에 대응시켜 표현 → 체르노프 페이스. ← 정답
- **④** 행렬 형태의 칸을 색상으로 채워 값의 크기를 비교. 얼굴 요소와 무관.

**출제 포인트:** 비교 시각화 3대 특징 매칭 — 얼굴 요소=체르노프 페이스, 방사형(거미줄) 축=스타 차트, 평행한 다변량 축=평행 좌표 그래프.

**근거:** 체르노프 페이스(Chernoff faces)는 다변량 데이터의 각 변수를 사람 얼굴의 요소에 대응시켜 얼굴 형태의 차이로 데이터를 비교하는 비교 시각화 기법이다.
</details>

### Q4-045 [난이도: 중] [태그: 4과목/분석결과해석및활용/시각화절차]

빅데이터 시각화 절차 3단계를 순서대로 바르게 나열한 것은?

① 시각화 → 구조화 → 시각표현
② 구조화 → 시각화 → 시각표현
③ 구조화 → 시각표현 → 시각화
④ 시각표현 → 구조화 → 시각화

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** 시각화 도구 적용보다 데이터·목표의 구조화가 먼저여야 하므로 틀림.
- **②** 구조화(목표 설정·데이터 정리) → 시각화(도구·기법으로 표현) → 시각표현(그래픽 요소 다듬어 완성도 제고). ← 정답
- **③** 시각표현은 마지막 보정 단계이므로 시각화보다 앞설 수 없음.
- **④** 시각표현이 첫 단계가 될 수 없음.

**출제 포인트:** "구·시·표"로 암기 — 구조화(무엇을 보여줄지 정리) → 시각화(차트로 만들기) → 시각표현(색·레이블·인터랙션 등으로 다듬기).

**근거:** 빅데이터 시각화 절차는 데이터와 시각화 목표를 정리하는 구조화, 시각화 도구·기법으로 표현하는 시각화, 그래픽 요소를 보정해 정보 전달력을 높이는 시각표현의 3단계로 수행된다.
</details>

### Q4-046 [난이도: 중] [태그: 4과목/분석결과해석및활용/비교시각화]

다음 중 비교 시각화 기법에 해당하지 <u>않는</u> 것은?

① 히트맵(heatmap)
② 스타 차트(star chart)
③ 평행 좌표 그래프(parallel coordinates)
④ 등치지역도(choropleth map)

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 색상으로 여러 항목·변수의 값 크기를 한눈에 비교 → 비교 시각화.
- **②** 방사형 축의 다각형으로 여러 대상의 다변량 값을 비교 → 비교 시각화.
- **③** 평행한 변수 축들을 선으로 연결해 다변량 데이터를 비교 → 비교 시각화.
- **④** 지도 위 지역별 값을 색상 농도로 표현 → 공간 시각화. 비교 시각화가 아님. ← 정답

**출제 포인트:** 비교 시각화 = 히트맵·체르노프 페이스·스타 차트·평행 좌표 그래프. "지도"가 나오면 무조건 공간 시각화.

**근거:** 비교 시각화는 여러 변수·항목 간 값의 차이를 비교하기 위한 시각화 유형으로 히트맵·체르노프 페이스·스타 차트·평행 좌표 그래프가 대표적이다.
</details>

### Q4-047 [난이도: 중] [태그: 4과목/분석결과해석및활용/관계시각화]

다음 중 관계 시각화 기법으로만 묶인 것은?

① 산점도, 버블 차트, 히스토그램
② 산점도, 파이 차트, 히트맵
③ 버블 차트, 트리맵, 선 그래프
④ 히스토그램, 도넛 차트, 카토그램

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** 산점도·버블 차트·히스토그램 모두 관계 시각화. ← 정답
- **②** 산점도는 관계 시각화이나, 파이 차트는 분포·히트맵은 비교 시각화.
- **③** 버블 차트는 관계 시각화이나, 트리맵은 분포·선 그래프는 시간 시각화.
- **④** 히스토그램은 관계 시각화이나, 도넛 차트는 분포·카토그램은 공간 시각화.

**출제 포인트:** 관계 시각화 = 산점도·산점도 행렬·버블 차트·히스토그램. 버블 차트는 산점도에 크기(제3의 변수)를 더한 확장형.
※ 교재별 표기 차이 있음 — 히스토그램을 분포 시각화로 분류하는 교재도 있으나, KDATA 계열 교재는 관계 시각화로 분류하는 것이 다수.

**근거:** 관계 시각화는 변수 간의 연관성·상관관계를 표현하는 시각화 유형으로 산점도·산점도 행렬·버블 차트·히스토그램이 대표적이다.
</details>

### Q4-048 [난이도: 중] [태그: 4과목/분석결과해석및활용/공간시각화]

다음 중 공간 시각화 기법으로만 묶인 것은?

① 도트맵, 트리맵, 카토그램
② 등치지역도, 히트맵, 버블 플롯맵
③ 등치지역도, 도트맵, 카토그램
④ 카토그램, 버블 차트, 계단식 그래프

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 도트맵·카토그램은 공간 시각화이나, 트리맵은 분포 시각화.
- **②** 등치지역도·버블 플롯맵은 공간 시각화이나, 히트맵은 비교 시각화.
- **③** 등치지역도·도트맵·카토그램 모두 지도 기반의 공간 시각화. ← 정답
- **④** 카토그램은 공간 시각화이나, 버블 차트는 관계·계단식 그래프는 시간 시각화.

**출제 포인트:** 공간 시각화 4총사 = 등치지역도(코로플레스)·도트맵·카토그램·버블 플롯맵. 지도 위가 아닌 버블 "차트"는 관계 시각화라는 점이 단골 함정.

**근거:** 공간 시각화는 지도 위에 위치 정보와 결합하여 데이터를 표현하는 시각화 유형으로 등치지역도·도트맵·카토그램·버블 플롯맵이 대표적이다.
</details>

### Q4-049 [난이도: 중] [태그: 4과목/분석결과해석및활용/평행좌표그래프]

여러 노트북 제품을 가격·무게·성능·배터리 시간 등 4개 이상의 변수에 대해 한 화면에서 동시에 비교하려고 한다. 각 변수를 평행한 세로 축으로 배치하고 제품마다 축 위의 값을 선으로 이어 표현하기에 가장 적절한 기법은?

① 평행 좌표 그래프(parallel coordinates)
② 파이 차트(pie chart)
③ 선 그래프(line graph)
④ 도트맵(dot map)

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** 다변량(변수 여러 개) 데이터를 평행한 변수 축 위의 꺾은선으로 표현해 여러 대상을 비교 → 상황에 정확히 부합. ← 정답
- **②** 한 변수의 구성 비율만 표현 가능. 다변량 비교 불가.
- **③** 가로 축이 시간인 추세 표현용. 변수별 평행 축 개념이 없음.
- **④** 지도 위 분포 표현용 공간 시각화. 제품 비교와 무관.

**출제 포인트:** 평행 좌표 그래프의 시그니처 = "다변량 + 평행한 축 + 선으로 연결". 선 그래프(시간 축 1개)와 혼동시키는 함정에 주의.

**근거:** 평행 좌표 그래프(parallel coordinates)는 여러 변수를 평행한 축에 나란히 배치하고 각 개체의 값을 선으로 연결하여 다변량 데이터를 비교하는 비교 시각화 기법이다.
</details>

### Q4-050 [난이도: 중] [태그: 4과목/분석결과해석및활용/인포그래픽]

인포그래픽(infographic)에 대한 설명으로 옳지 <u>않은</u> 것은?

① 정보(information)와 그래픽(graphic)의 합성어로, 복잡한 정보를 그래픽으로 표현한 것이다.
② 도표·일러스트 등을 활용해 정보를 쉽고 빠르게 전달하며 대중의 흥미를 유발한다.
③ 스토리텔링 방식으로 메시지를 전달할 수 있어 홍보·보도 자료 등에 널리 활용된다.
④ 분석 전문가를 대상으로 원시 데이터와 통계 수치를 표 형태로 빠짐없이 나열하는 것을 목적으로 한다.

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 옳은 설명. 인포그래픽의 어원이자 기본 정의.
- **②** 옳은 설명. 쉽고 빠른 전달과 흥미 유발이 인포그래픽의 핵심 장점.
- **③** 옳은 설명. 스토리텔링 기반 전달로 기억에 오래 남는다.
- **④** 인포그래픽은 **일반 대중**이 정보를 **쉽게 이해**하도록 요약·시각화하는 것이 목적이다. 전문가용 수치 나열은 정반대의 설명. ← 정답

**출제 포인트:** 인포그래픽 키워드 = 대중·쉬움·빠른 전달·흥미·스토리텔링. "전문가·상세 수치·표 나열"이 나오면 틀린 선지.

**근거:** 인포그래픽은 정보와 그래픽의 합성어로, 복잡한 정보를 도표·이미지 등으로 시각화하여 일반 대중이 쉽고 빠르게 이해하도록 전달하는 시각화 방법이다.

### Q4-051 [난이도: 상] [태그: 4과목/분석결과해석및활용/시각화유형매칭]

시각화 유형과 차트의 매칭에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. 계단식 그래프(step chart)는 시간 시각화 기법이다.
- ㄴ. 트리맵(treemap)은 비교 시각화 기법이다.
- ㄷ. 버블 차트(bubble chart)는 관계 시각화 기법이다.
- ㄹ. 히트맵(heatmap)은 비교 시각화 기법이다.

① ㄱ, ㄴ, ㄷ  ② ㄱ, ㄷ, ㄹ  ③ ㄴ, ㄷ, ㄹ  ④ ㄱ, ㄴ, ㄹ

<details><summary>정답 및 해설</summary>

**정답: ②**

- **ㄱ (O)** 계단식 그래프는 값이 유지되다 특정 시점에 변하는 모습을 표현하는 시간 시각화.
- **ㄴ (X)** 트리맵은 전체 대비 비율·계층을 면적으로 표현하는 **분포** 시각화.
- **ㄷ (O)** 버블 차트는 산점도에 원의 크기(제3의 변수)를 더한 관계 시각화.
- **ㄹ (O)** 히트맵은 색상으로 여러 변수·항목의 값을 비교하는 비교 시각화.

따라서 옳은 것은 ㄱ, ㄷ, ㄹ → **②**. (①·④는 틀린 ㄴ을 포함, ③은 옳은 ㄱ을 누락하고 ㄴ을 포함)

**출제 포인트:** 5유형 매칭 총정리 — 시간(막대·선·영역·계단) / 분포(파이·도넛·트리맵·누적영역) / 관계(산점도·버블·히스토그램) / 비교(히트맵·체르노프·스타·평행좌표) / 공간(등치지역도·도트맵·카토그램·버블플롯맵).

**근거:** 데이터 시각화는 표현 목적에 따라 시간·분포·관계·비교·공간 시각화의 5유형으로 나뉘며 각 유형마다 대표 차트가 정해져 있다.
</details>

### Q4-052 [난이도: 상] [태그: 4과목/분석결과해석및활용/공간시각화특징]

공간 시각화 기법의 특징에 대한 설명으로 옳지 <u>않은</u> 것은?

① 등치지역도(choropleth map)는 지역별 값을 색상의 음영·농도로 표현하며, 면적이 큰 지역이 실제 값보다 강조되어 보이는 왜곡이 생길 수 있다.
② 도트맵(dot map)은 데이터 값을 지도 위 점의 개수·밀도로 표현하여 분포 양상을 보여준다.
③ 카토그램(cartogram)은 지역의 실제 면적을 그대로 유지한 채 색상만으로 데이터 값을 표현한다.
④ 버블 플롯맵(bubble plot map)은 지도 위 해당 위치에 원의 크기로 데이터 값을 표현한다.

<details><summary>정답 및 해설</summary>

**정답: ③**

- **①** 옳은 설명. 등치지역도는 색상 농도 방식이라 면적이 큰 지역이 과대 강조되는 단점이 있고, 이를 보완하는 것이 카토그램이다.
- **②** 옳은 설명. 점의 개수·밀도로 분포를 표현하는 것이 도트맵.
- **③** 카토그램은 면적을 유지하는 것이 아니라 **값에 비례해 면적을 왜곡**하는 기법이다. "실제 면적 유지 + 색상 표현"은 등치지역도의 설명. ← 정답
- **④** 옳은 설명. 위치 + 원의 크기로 값을 표현하는 것이 버블 플롯맵.

**출제 포인트:** 함정 패턴 = 등치지역도와 카토그램의 특징 바꿔치기. "색상 농도·면적 유지=등치지역도, 면적 왜곡=카토그램"으로 짝을 고정해 암기.

**근거:** 카토그램은 등치지역도의 면적에 따른 왜곡 문제를 보완하기 위해 데이터 값에 비례하여 지역 면적 자체를 변형해 표현하는 공간 시각화 기법이다.
</details>
