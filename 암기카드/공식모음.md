# 빅데이터분석기사 계산 공식 암기카드

## 1. 확률·분포·추정

| 이름(원어) | 공식 | 계산 예 |
|---|---|---|
| 조건부확률 (Conditional Probability) | P(B\|A) = P(A∩B) / P(A) — 분모는 조건 사건 P(A) | P(A∩B)=0.2, P(A)=0.5 → P(B\|A)=0.4 |
| 베이즈 정리 (Bayes' Theorem) | P(A\|D) = P(A)P(D\|A) / Σ P(원인)P(D\|원인) — 분모는 전확률(모든 경로의 합) | P(A)=0.3, P(D\|A)=0.8, P(B)=0.7, P(D\|B)=0.2 → 0.24/(0.24+0.14)≈0.632 |
| 베르누이 기댓값·분산 (Bernoulli) | E(X)=p, V(X)=p(1−p) | p=0.3 → E=0.3, V=0.3×0.7=0.21 |
| 이항분포 기댓값·분산 (Binomial) | E(X)=np, V(X)=np(1−p) — (1−p) 빼먹으면 포아송과 혼동 | n=100, p=0.2 → E=20, V=100×0.2×0.8=16 |
| 포아송 기댓값·분산 (Poisson) | E(X)=λ, V(X)=λ — 기댓값=분산이 최대 특징 | λ=5 → E=5, V=5 |
| 표본평균 분포·중심극한정리 (CLT) | X̄ ~ 근사 N(μ, σ^2/n), 표준오차 = σ/√n — 모집단 분포와 무관 | σ=10, n=25 → 표준오차 = 10/5 = 2 |
| 검정력 (Power) | 검정력 = 1 − β = P(H0 기각 \| H0 거짓) | β=0.2 → 검정력 = 0.8 |
| 계통추출 간격 (Systematic Sampling) | k = N / n (N=모집단, n=표본 크기) | N=1,000, n=50 → k=20 |
| 변수 쌍 개수 (Pairs of Variables) | p(p−1)/2 — 산점도 행렬의 서로 다른 쌍 수 | p=5 → 5×4/2 = 10쌍 |
| 불편성 (Unbiasedness) | E(θ̂) = θ — 추정량의 기댓값이 모수와 같음 | E(X̄)=μ 이면 X̄는 μ의 불편추정량 |

## 2. 연관분석·교차표

| 이름(원어) | 공식 | 계산 예 |
|---|---|---|
| 지지도 (Support) | P(A∩B) — 전체 거래 중 A·B 동시 구매 비율 | 100건 중 동시 구매 20건 → 0.2 |
| 신뢰도 (Confidence) | P(A∩B)/P(A) = P(B\|A) — 분모는 조건 항목 A | P(A∩B)=0.2, P(A)=0.4 → 0.5 |
| 향상도 (Lift, 연관규칙) | 신뢰도/P(B) = P(A∩B)/(P(A)×P(B)) — 곱하기 아니라 나누기, 1이면 독립 | 신뢰도 0.5, P(B)=0.25 → 향상도 2 |
| 기대빈도 (Expected Frequency) | (행 합계 × 열 합계) ÷ 전체 표본 수 — 독립성 검정용 | 행합 40, 열합 50, 전체 200 → 40×50/200 = 10 |
| 카이제곱 통계량 (Chi-square Statistic) | Σ (관측도수 − 기대도수)^2 / 기대도수 — 독립성·적합도 검정 공통 | 관측 30, 기대 20 → (30−20)^2/20 = 5 (셀별 합산) |

## 3. 회귀 평가 지표

| 이름(원어) | 공식 | 계산 예 |
|---|---|---|
| 결정계수 (R², Coefficient of Determination) | R² = SSR/SST = 1 − SSE/SST (SST=SSR+SSE) | SST=100, SSE=25 → R²=0.75 |
| MSE (Mean Squared Error) | (1/n) Σ (y − ŷ)^2 — 단위는 종속변수의 제곱 | 오차 (1, −2, 1) → (1+4+1)/3 = 2 |
| RMSE (Root Mean Squared Error) | √MSE — 종속변수와 같은 단위 | MSE=4 → RMSE=2 |
| MAE (Mean Absolute Error) | (1/n) Σ \|y − ŷ\| — 절댓값 평균, 이상값 영향 작음 | 오차 (1, −2, 1) → (1+2+1)/3 ≈ 1.33 |
| MAPE (Mean Absolute Percentage Error) | (100/n) Σ \|(y − ŷ)/y\| — % 지표, 단위 없음 | 실제 100, 예측 90 한 건 → 10% |

## 4. 분류 평가 지표 (혼동행렬)

혼동행렬 (Confusion Matrix):

|  | 예측 양성(P) | 예측 음성(N) |
|---|---|---|
| **실제 양성** | TP | FN |
| **실제 음성** | FP | TN |

공통 예시 행렬: TP=40, FN=10, FP=20, TN=30 (전체 100)

| 이름(원어) | 공식 | 계산 예 |
|---|---|---|
| 정확도 (Accuracy) | (TP+TN) / 전체 | (40+30)/100 = 0.7 |
| 정밀도 (Precision) | TP/(TP+FP) — 분모는 예측 양성 | 40/(40+20) ≈ 0.667 |
| 재현율·민감도·TPR (Recall, Sensitivity) | TP/(TP+FN) — 분모는 실제 양성 | 40/(40+10) = 0.8 |
| 특이도 (Specificity) | TN/(TN+FP) — 분모는 실제 음성 | 30/(30+20) = 0.6 |
| FPR (False Positive Rate) | FP/(FP+TN) = 1 − 특이도 — 특이도 먼저 구해 검산 | 20/(20+30) = 0.4 = 1−0.6 |
| F1-점수 (F1 Score) | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) — 조화평균 | P=0.75, R=0.5 → 2×0.375/1.25 = 0.6 |
| ROC 좌표 (ROC Coordinates) | (x, y) = (FPR, TPR) — x가 FPR, y가 TPR | FPR=0.4, TPR=0.8 → 점 (0.4, 0.8) |
| 향상도 (Lift, 이익도표) | 구간 반응률 ÷ 전체 평균 반응률 — 나눗셈이지 차이 아님 | 구간 20%, 전체 5% → 20/5 = 4 |

## 5. 기타 (전처리·통계요약·모형·분석기획)

| 이름(원어) | 공식 | 계산 예 |
|---|---|---|
| 민맥스 정규화 (Min-Max Normalization) | (x − min) / (max − min) — 결과 [0,1], 분자·분모 모두 최솟값 빼기 | x=70, min=50, max=100 → 20/50 = 0.4 |
| Z-점수 표준화 (Z-score Standardization) | Z = (x − 평균) / 표준편차 — \|Z\|>3이면 이상값 의심 | x=80, 평균=70, 표준편차=5 → Z=2 |
| IQR (Interquartile Range) | IQR = Q3 − Q1, 이상값 경계 = Q1−1.5×IQR, Q3+1.5×IQR | Q1=20, Q3=40 → IQR=20, 경계 −10 ~ 70 |
| 변동계수 (CV, Coefficient of Variation) | CV = 표준편차 ÷ 평균 — 단위 없는 상대 산포, 단위 다른 자료 비교 | 표준편차 5, 평균 25 → 0.2 |
| 범위 (Range) | 최댓값 − 최솟값 — 극단값 2개만 사용, 이상값에 민감 | 최대 95, 최소 40 → 55 |
| 시그모이드 (Sigmoid) | f(x) = 1 / (1 + e^(−x)) — 출력 0~1, 이진 분류 출력층 | x=0 → 1/(1+1) = 0.5 |
| tanh (Hyperbolic Tangent) | f(x) = (e^x − e^(−x)) / (e^x + e^(−x)) — 출력 −1~1 | x=0 → 0/2 = 0 |
| ReLU (Rectified Linear Unit) | f(x) = max(0, x) — 출력 0~∞, 기울기 소실 완화 | x=−3 → 0, x=2 → 2 |
| 소프트맥스 (Softmax) | f(x_i) = e^(x_i) / Σ_j e^(x_j) — 다중 클래스 확률, 합=1 | 두 클래스 값이 같으면 각 0.5 |
| 오즈 (Odds) | odds = p / (1 − p) — 범위 0~∞, 성공이 실패의 몇 배 | p=0.8 → 0.8/0.2 = 4 |
| 오즈비 (Odds Ratio) | e^β (로지스틱 회귀계수의 지수 변환) — 독립변수 1단위 증가 시 오즈 e^β배 | β=0.7 → e^0.7 ≈ 2.01배 |
| TF-IDF (Term Frequency–Inverse Document Frequency) | TF × IDF — 흔한 단어일수록 IDF↓ → 가중치↓ | TF=3, IDF=2 → 6 |
| 정보이득 (Information Gain) | 분리 전 불순도 − 분리 후 불순도 — 이득 최대인 분리 선택 | 분리 전 0.5, 분리 후 0.3 → 이득 0.2 |
| ROI (Return on Investment) | 순이익 ÷ 투자비 × 100 — 분모는 투자비만 | 순이익 500, 투자비 2,000 → 25% |
| NPV (Net Present Value) | 미래 현금흐름의 현재가치 − 투자비 — 0보다 크면 투자 타당 | 현재가치 2,500, 투자비 2,000 → NPV=500>0 타당 |
| 투자 회수 기간 (Payback Period) | 투자비 ÷ 연간 순이익 (순이익 균등 시) — 짧을수록 유리 | 12,000만 ÷ 3,000만 = 4년 |
| 그리드 서치 조합 수 (Grid Search Combinations) | 각 하이퍼파라미터 후보 수의 곱 | 3종 × 각 4개 = 4×4×4 = 64조합 |
