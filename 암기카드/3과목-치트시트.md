# 3과목 빅데이터 모델링 — 치트시트

## ① 세부항목 핵심 표

### 학습 유형
| 유형 | 키워드 | 대표 기법 |
|---|---|---|
| 지도 | 레이블·정답 | 회귀, 로지스틱, 의사결정나무, SVM, 신경망 |
| 비지도 | 군집·패턴·구조 | K-means·계층적·DBSCAN·SOM, 연관(Apriori), PCA, 오토인코더 |
| 강화 | 에이전트·보상·정책·환경 | Q-learning 계열 |
| 준지도 | 소량 레이블+대량 무레이블 | 지도·비지도의 **중간 별도 유형** (비지도 아님) |

- 분류 vs 회귀 = 목표변수 형태: 범주형(여부·등급·스팸)=분류 / 연속형(가격·매출액·판매량)=회귀
- 변수 선택 3기법 = 전진 선택 · 후진 소거 · 단계적 선택
- 좋은 변수 = 목표변수와 관련성↑ + 독립변수 간 중복(다중공선성)↓

### 데이터 3분할
| 데이터 | 역할 |
|---|---|
| 훈련(train) | 파라미터(가중치) 학습 |
| 검증(validation) | 하이퍼파라미터 튜닝 + 과대적합 확인 |
| 평가(test) | 최종 일반화 성능 측정만 (학습·튜닝 금지) |

### 분석 도구
| 구분 | R | Python | SAS/SPSS |
|---|---|---|---|
| 성격 | 통계 특화·인메모리 | 범용·연동성 | 상용 라이선스 |
| 저장소/특징 | CRAN | PyPI (pandas=라이브러리) | 벤더 기술지원, SPSS=GUI |
- 오픈소스 = 무료 + 최신 기법 반영 빠름 / 상용 = 기술지원 + 반영 느림

### 회귀 가정 → 진단 ("독왓, 정샤, 등산, 다V")
| 가정 | 진단 도구 |
|---|---|
| 독립성 | 더빈-왓슨 ≈2 독립 / 0 양의 자기상관 / 4 음의 자기상관 |
| 정규성 | 샤피로-윌크, K-S, Q-Q플롯 |
| 등분산성 | 잔차 산점도 (깔때기=이분산=위배) |
| 다중공선성 | VIF>10 의심 → 변수제거·PCA·릿지 |
- 다중공선성 = **독립변수들 사이** 상관 문제 (종속-독립 아님)

### 로지스틱 회귀
- 종속변수 = 범주형, 시그모이드 1/(1+e⁻ˣ)로 확률화
- e^β = 오즈비 / 범위: 확률 0~1, 오즈 0~∞, 로짓 -∞~+∞

### 활성화 함수
| 함수 | 식/범위 | 용도 |
|---|---|---|
| 시그모이드 | 1/(1+e⁻ˣ), 0~1 | 이진 분류 출력층 |
| tanh | -1~1 | 은닉층 |
| ReLU | max(0,x), 0~∞ | 은닉층, 기울기 소실 완화 |
| 소프트맥스 | 지수/지수합, 합=1 | 다중 분류 출력층 |
- 신경망 史: 단층(XOR 불가)→다층(은닉층)→역전파→기울기 소실(시그모이드 미분 최대 0.25)→ReLU

### SVM
- 마진 **최대화** / 서포트 벡터 = 경계에 **가장 가까운** 점 / 커널 트릭 = 고차원 매핑 / 슬랙 변수 = 오분류 허용(소프트 마진)

### 군집
| 항목 | 내용 |
|---|---|
| K-means 단점 | K 사전 지정, 초기 중심 민감, 이상값 민감 |
| 연결법 | 단일=최단, 완전=최장, 평균=평균, 와드=분산(오차제곱합) 증가 최소 |
| 계층적 | 병합 후 번복 불가, 군집 수 사후 결정(덴드로그램) |
| DBSCAN | 밀도 기반(ε·minPts), K 불필요, 노이즈 식별 |
| 실루엣 | -1~1: 1 양호 / 0 경계 / 음수 오배정 |
| SOM | 비지도 신경망, 저차원 격자, 위상 보존, 경쟁학습(역전파 X) |

### 딥러닝 매칭
| 모델 | 키워드 |
|---|---|
| CNN | 이미지, 합성곱+풀링+완전연결 |
| RNN/LSTM | 순차 데이터, LSTM=게이트(입력·망각·출력)로 기울기 소실·장기 의존성 해결 |
| GAN | 생성자 vs 판별자 **적대적 경쟁** (협력 아님) |
| 오토인코더 | 비지도, 인코더+디코더, 차원축소·복원오차 이상탐지 |

### 텍스트·SNA
- TF-IDF = TF×IDF, 흔한 단어일수록 가중치↓ / 불용어 = 흔하지만 무의미 → **제거**
- LDA = 문서=토픽 혼합, 토픽=단어 확률분포 / 감성분석 = 비정형 텍스트의 긍부정
- SNA 중심성: 직접 연결 수=연결 / 다리·중개=매개 / 최단거리 가까움=근접 / 이웃의 중요도=위세

### 앙상블
| | 배깅 | 부스팅 |
|---|---|---|
| 학습 | 병렬·독립 (부트스트랩 복원추출) | 순차·의존 (오분류 가중치) |
| 효과 | 분산↓ | 편향↓ |
| 대표 | 랜덤포레스트 | AdaBoost·GBM·XGBoost |
- 보팅: 하드=클래스 다수결 / 소프트=**확률 평균**

### 범주형·시계열·비모수
- 카이제곱 3용도: 적합도(변수1, 이론분포) / 독립성(표본1·변수2) / 동질성(표본 여러 개)
- 기대빈도 5 미만 소표본 → 피셔 정확 검정
- 정상성 3조건: 평균 일정·분산 일정·공분산은 시차에만 의존 / 평균 비정상→차분, 분산 비정상→로그 변환
- 시계열 4요소: 추세·계절(주기 고정, 1년 이내)·순환(주기 불규칙·장기)·불규칙
- ARIMA(p,d,q): p=AR(과거 자기 값) / d=차분 횟수 / q=MA(과거 오차)
- 백색잡음 = 평균 0, 분산 일정, 자기상관 없음
- 나이브베이즈 = 베이즈 정리 + 변수 조건부 독립 **가정**(단순화용)
- 비모수 대응: 대응 2표본=윌콕슨 부호순위(·부호검정)↔대응 t / 독립 2표본=만-휘트니 U(=윌콕슨 순위합)↔독립 t / 독립 3집단+=크루스칼-왈리스↔ANOVA / 런 검정=무작위성

## ② 순서 암기
- 모형 구축: 요건 정의 → 모델링 → 검증·테스트 → 적용 ("요·모·검·적")
- K-means: 초기화(K·중심) → 할당 → 중심 갱신 → 수렴까지 반복
- 텍스트 전처리: 코퍼스 → 토큰화 → 불용어 제거 → 형태소 분석
- 신경망: 단층 XOR 한계 → 다층 → 역전파 → 기울기 소실 → ReLU

## ③ 매칭 암기
- 의사결정나무: **CART=지니(이진분리) / C4.5·ID3=엔트로피 / CHAID=카이제곱(다지분리)** — "카트는 지니, C4.5는 엔진, 차이는 카이"
- 연관분석: 지지도=P(A∩B) / 신뢰도=P(A∩B)/P(A) / 향상도=신뢰도/P(B) → >1 양의 연관, =1 독립, <1 음의 연관
- Apriori: 비빈발 집합의 상위집합=비빈발, 가지치기 기준=**최소 지지도** (향상도 X), 부분집합 지지도 ≥ 원집합
- 딥러닝 사례: 생성→GAN / 라벨 없음·압축·복원오차→오토인코더 / 긴 문맥·순차→LSTM / 이미지→CNN

## ④ 함정 포인트
- 로지스틱 "회귀"지만 = 지도학습·**분류** / K-means K 사전 지정≠지도학습 / SOM은 신경망이지만 **비지도**
- 준지도학습 ≠ 비지도의 하위 유형 (레이블 사용 여부가 기준)
- "변수 많을수록/항상 좋다" = 오답 (과대적합·차원의 저주)
- 평가 데이터로 튜닝 → 일반화 성능 **과대평가** (튜닝은 검증 데이터)
- 엔트로피 0 = **완전 순수** (불순도 최대 아님; 이진 최대 = 지니 0.5·엔트로피 1)
- 서포트 벡터 = 가장 **가까운** 점 ("가장 먼" = 함정)
- 단일 연결법 = 최단 거리 ("가장 먼" = 완전 연결법)
- 계층적 군집 재배정 불가 (재배정은 K-means)
- 오즈는 0~1 아님 (0~∞)
- 정상 시계열 분산도 일정 ("분산은 변해도 됨" = 함정)
- 오토인코더 = 비지도 ("출력을 입력과 비교하니 지도" = 함정)
- GAN "협력·동일 목적" = 함정 (적대적 경쟁)
- 부스팅에 "독립·병렬" 붙이면 오답 (그건 배깅) / 랜덤포레스트 = 배깅 계열
- 비모수 검정 "검정력 항상 높다" = 오답 (가정 충족 시 모수 검정이 우위)
- 상용 도구가 최신 기법 반영 빠르다 = 오답 (빠른 쪽은 오픈소스)
- 통계 기반 모형 "검정 없이·확률 해석 불가" = 오답 (가정·검정·추론이 본질)
