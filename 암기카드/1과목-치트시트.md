# 1과목 빅데이터 분석 기획 — 치트시트

## ① 세부항목별 핵심 표

### DIKW (사례 판별)
| 계층 | 판별 키워드 |
|---|---|
| 데이터 | 가공 안 된 객관적 사실 (A마트 1,000원) |
| 정보 | 비교·가공해 의미 부여 (200원 더 싸다) |
| 지식 | 행동 방침으로 구조화 (A마트에서 사야겠다) |
| 지혜 | 다른 상황까지 추론 (다른 상품도 쌀 것) |

### 빅데이터 V
| 확장 | 구성 |
|---|---|
| 3V | Volume(규모)·Velocity(속도)·Variety(다양성) |
| 5V | +Veracity(신뢰성·품질)·Value(가치) |
| 7V | +Validity(정확성)·Volatility(휘발성=유효기간) ※교재차이 |
- "실시간·생성 속도"=Velocity, "형태"=Variety, "품질"=Veracity

### 데이터 유형
| 유형 | 판별 | 예 | 수집 기술 |
|---|---|---|---|
| 정형 | 고정 스키마 테이블 | RDB 테이블 | ETL·Sqoop |
| 반정형 | 메타데이터(태그·키) 내장 | XML·JSON·HTML·로그 | Flume·Scribe·Chukwa |
| 비정형 | 구조 없음 | 동영상·음성·이미지·텍스트 | 크롤링·Scrapy |

- 가치 산정 곤란 3이유 = **활·창·기** (활용 다변화·새 가치 창출·기술 발전)
- 하드 스킬 = 이론 지식+분석 기술 / 소프트 스킬 = 통찰·전달(스토리텔링)·협력

### 분석 조직 구조 3유형
| 구조 | 누가 | 단점/특징 |
|---|---|---|

| 분산 | 전담 인력을 현업 배치 | 신속 실무 적용, 역할 분담 명확화 필요 |

### 제도
- 데이터 3법 = **개·망·신** (개인정보 보호법·정보통신망법·신용정보법) — 위치정보법 X
- 식별 스펙트럼: 개인정보(식별O, 법O) > 가명정보(추가 정보 결합 시 식별, **법 적용 O**) > 익명정보(식별X, **법 적용 X**)
- 가명정보 동의 없는 처리 3목적 = **통·과·공** (통계작성·과학적 연구·공익적 기록보존) — 맞춤 광고 X
- 마이데이터 = 정보주체 본인 + 전송요구권 + 기계 판독 가능 형태 (전 분야 확대)
- 개인정보 = 살아 있는 개인만, 목적 외 이용 금지, 최소 수집, 익명 우선→곤란 시 가명

### 비식별화 5기법
| 기법 | 예 |
|---|---|
| 가명처리 | 홍길동→임꺽정 (휴리스틱 대체) |
| 총계처리 | 개별 값→평균·총합 (라운딩·재배열) |
| 데이터 삭제 | 항목 자체를 없앰 |
| 데이터 범주화 | 33세→30대 |
| 데이터 마스킹 | 홍길동→홍** (가리되 남김) |

### 데이터 품질 4기준
정확성=맞는 값 / 완전성=누락 없음 / 적시성=제때 최신 / 일관성=형식·값 체계 무모순

### 데이터 변환 5기법 (목적으로 판별)
평활화=노이즈 제거 / 집계=합산·요약(일별→월별) / 일반화=상위 개념 대체(나이→연령대) / 정규화=척도 변환(0~1, 최소-최대·Z-점수) / 속성 생성=새 속성(키·몸무게→BMI)

### NoSQL
- 유형-제품: **Key-Value=Redis / Document=MongoDB / Column=HBase·Cassandra / Graph=Neo4j**
- CAP = 일관성(모든 노드 동일 데이터)·가용성(항상 응답)·분할 허용성, **최대 2개** → 분산은 P 전제, CP vs AP 택일
- ACID(원자성·일관성·독립성·지속성)=RDBMS·은행 / BASE(기본적 가용성·소프트 상태·최종 일관성)=NoSQL·SNS

## ② 순서 암기
- KDD 5단계: 선택→전처리→변환→마이닝→해석·평가 (**선-전-변-마-해**)
- CRISP-DM 6단계: 업무 이해→데이터 이해→데이터 준비→모델링→평가→전개 (**업-데이-데준-모-평-전**)
- SEMMA 5단계: Sample→Explore→Modify→Model→Assess
- 단계 수 = **KDD 5 / CRISP-DM 6 / SEMMA 5 (5-6-5)**
- CRISP-DM 4계층: 단계→일반화 태스크→세분화 태스크→프로세스 실행 (**단-일-세-프**)
- 하향식 발굴: 문제 탐색→문제 정의→해결방안 탐색→타당성 검토 (**탐-정-해-타**)
- 성숙도 4단계: 도입→활용→확산→최적화
- 데이터 확보 계획: 목표 정의→요구사항 도출→예산안 수립→계획 수립 (**목-요-예-계**)
- 분석 WBS 4단계: 과제 정의→준비·탐색→모델링·검증→산출물 정리 (**정-준-모-산**)
- ETL: 추출→변환→적재 / ELT: 추출→적재→변환

## ③ 매칭 암기
- 사분면(준비도·성숙도): 低低=준비형 / 低高=정착형 / **高低=도입형** / 高高=확산형
- 우선순위 2기준: 시급성=전략적 중요도·목표 가치(Value) / 난이도=데이터 비용·분석 수준(3V=투자비용) → 시급성 高+난이도 易 최우선
- 하향식=문제 주어짐·수렴 / 상향식=문제 정의 곤란·데이터 기반·발산 / 프로토타이핑=시도→반복 개선 / 디자인 씽킹=발산+수렴 반복
- 분석 기획 고려 3 = 가용 데이터·유스케이스·장애요소 사전계획
- 분석 목표 정의서 3요소 = **원·방·평** (원천 데이터 조사·분석 방안 판단·성과 평가 기준)
- WBS=계층적 작업 분할 / 간트 차트=일정 막대 시각화

## ④ 함정 포인트
- Veracity·Value는 3V 아님(5V 추가분) / Volatility=유효기간(7V)
- 반정형은 메타데이터를 **포함**한다 (구조 파악 가능) — "메타데이터 없음"은 오답
- Pig↔Sqoop 바꿔치기: Pig=Pig Latin 처리, Sqoop=RDB 전송 / Hive=HiveQL
- 전개(Deployment)·업무 이해는 **CRISP-DM에만** 있음, "변환"이 독립 단계면 KDD
- SEMMA는 데이터(샘플)에서 출발 — 비즈니스 이해 단계 없음
- 시급성↔난이도 정의 바꿔치기: "전략적 중요도"는 시급성
- 하이퍼파라미터·서버 사양·대시보드 = 기획 단계 아님(수행 단계)
- ETL 선지에 "추출→적재→변환" 나오면 ELT 함정
- 척와·크롤링을 정형에 연결하면 오답 (척와=반정형 로그, 크롤링=비정형)
- FTP: 능동=서버가 접속 시작, 수동=클라이언트가 접속 / UDP 아님(TCP)
- 적시성↔일관성 정의 바꿔치기 주의
- 일반화↔속성 생성 바꿔치기: 일반화=위로 뭉뚱그리기, 속성 생성=새로 만들기 / 나이→연령대는 평활화 아님(노이즈 제거 목적 아님)
- 마스킹≠삭제: 마스킹=가림, 삭제=없앰
- DW는 **비**휘발성 — "휘발성·실시간 갱신" 선지는 오답
- HDFS 역할 뒤집기: 네임노드=메타데이터, 데이터노드=실제 블록
- 마트에 레이크 특징(원시 무가공) 씌우면 오답 — 레이크=날것, 마트=완제품
- 컬럼 저장소는 컬럼 조회·집계에 **유리** (불리 아님)
- 가명정보는 개인정보(법 적용 O), 익명정보는 법 밖 / 특례에 "맞춤 광고" 없음
- 부정형에서 "제한 없이·자유롭게" 절대 표현 선지가 대개 정답
