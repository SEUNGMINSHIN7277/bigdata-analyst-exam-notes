# 2과목 빅데이터 탐색 — 치트시트

## ① 세부항목별 핵심 표

### 결측값 3유형 (판별: 결측이 무엇에 의존?)
| 유형 | 의존 대상 | 사례 |
|---|---|---|
| MCAR | 아무것도 아님(순수 우연) | 완전분석법이 안전한 유일 경우 |
| MAR | 관측된 다른 변수 | 성별 따라 체중 무응답률 차이 |
| MNAR | 결측된 값 자체 | 고소득자가 소득 무응답 |

### 결측값 대치법
| 방법 | 한 줄 정의 |
|---|---|
| 완전분석법 | 결측 있는 행 제외(표본 감소·MCAR 아니면 편향) |
| 평균 대치 | 평균으로 채움 → 분산 **과소추정** |
| 회귀 대치 | 회귀 예측값으로 대치 |
| 확률적 회귀 대치 | 예측값+오차항 → 변동성 보완 |
| 핫덱 | **같은(현재) 조사 내** 유사 응답자 값 |
| 콜드덱 | **외부·과거** 자료 값 |
| 다중 대치 | m회 대치→분석→결합 3단계("1회·1개" 아님) |

### 이상값 탐지
| 기법 | 기준 |
|---|---|
| ESD | 평균 ±3σ (정규 가정) |
| Z-점수 | 표준화 후 \|Z\|>3 |
| IQR 규칙 | [Q1−1.5×IQR, Q3+1.5×IQR] 밖 = 박스플롯 수염 밖 |
| 마할라노비스 | 공분산 반영·**다변량** |
| LOF | k-이웃과 **국소 밀도** 비교 |
| iForest | **적은 분할로 고립**되면 이상값 |

- 이상값 처리 4가지 = 삭제 · 대체(경계값) · 변환(로그) · 분리(그룹 나눠 각각 분석, 폐기 아님)
- 잡음 평활화 3형제 = 구간화(bin 대체) · 회귀(함수 적합) · 군집화(군집 밖 식별)
- 정제 대상 = 결측값(값 없음) / 잡음(값 왜곡, 무작위 오류) / 이상값(정상 범위 밖)

### 변수 선택 3방식
| 방식 | 정의 | 대표 |
|---|---|---|
| 필터 | 모델 없이 통계 측도, 비용 최저 | 상관계수·카이제곱·정보 이득 |
| 래퍼 | 부분집합마다 모델 반복 학습 | 전진·후진·단계적 |
| 임베디드 | 학습 안에 선택 내장 | 라쏘·릿지·엘라스틱넷 |

### 척도 4종 (순위?→간격?→절대영점?)
| 척도 | 특징 | 예 | 통계량 |
|---|---|---|---|
| 명목 | 분류만 | 혈액형 | 최빈값 |
| 순서 | 순위만 | 만족도 | +중앙값 |

### 표본추출 4종
| 방법 | 키워드 |

### 확률분포
| 분포 | 상황 | E(X), V(X) |
|---|---|---|

### 추론통계 핵심
| 항목 | 정의 |
|---|---|
| 불편성 | E(θ̂)=모수 |
| 효율성 | 분산 최소 |
| 일치성 | n↑ 수렴 |
| 충족성(충분성) | 표본 정보 모두 담음 |
| 1종 오류 α | 참인 H₀ 기각 |
| 2종 오류 β | 거짓 H₀ 채택 |

| p<α | 기각 / p≥α 기각 못 함 |

## ② 순서 암기
- 다중 대치: 대치 → 분석 → 결합
- 베이즈: 경로별 결합확률 → 전확률(합) → 해당 경로÷전확률
- 척도 판별: 순위? → 간격 일정? → 절대영점? (명목→순서→구간→비율)
- 텍스트 탐색: 토큰화 → 형태소 분석 → 단어 빈도 → 워드클라우드
- 양의 왜도(오른쪽 꼬리): 평균 > 중앙값 > 최빈값 (음의 왜도는 반대)

## ③ 매칭 암기
- EDA 4원칙 = **저·잔·재·현** (저항성·잔차·재표현·현시성) — "정규성"은 오답
- 검정 선택: 분산 알고 대표본=Z / 모르는 소표본=t / 범주형×범주형=카이제곱 / 3집단↑ 평균=ANOVA / 2집단=t / 사전·사후=대응 t
- 상관: 피어슨=연속·선형·모수 / 스피어만=순위·단조·비모수·이상값 저항
- 계수: 신뢰도(내적 일관성)=크론바흐 α / 평가자 일치=코헨 κ / 설명력=R²
- 공간 시각화: 색 농도=코로플레스맵 / 면적 변형=카토그램 / 원 크기=버블맵
- 비정형: 텍스트=형태소·워드클라우드 / 이미지=픽셀 행렬·히스토그램 / 오디오=파형·스펙트로그램
- 그래프: 연속형 분포=히스토그램(막대 붙임)·줄기-잎 / 범주형=막대그래프(간격) / 연속×연속=산점도 / 범주×범주=교차표·모자이크
- 대립가설 부호: ≠ 양측 / > 우측 단측 / < 좌측 단측 (H₀만 등호 포함)
- 변환: 양의 왜도→로그·제곱근 / 음의 왜도→제곱 / 정규성 계열(로그·박스콕스) vs 스케일링 계열(민맥스·표준화)

## ④ 함정 포인트
- MAR↔MNAR 정의 바꿔치기 최다 빈출: "결측값 자체 때문"=MNAR
- 평균 대치 → 분산 "커진다"(X) → **과소추정**(O)
- 마할라노비스 "상관 고려 못 함"(X) → 공분산 **반영**·다변량용(O)
- 래퍼가 "모델 없이 통계만"(X) → 그건 필터, 래퍼는 반복 학습·비용 큼
- PCA가 "클래스 분리·지도"(X) → 그건 LDA / PCA 주성분 "대등"(X) → 순서 있음(대등은 요인분석)
- MDS에 "목표변수 필요"(X) → 거리 행렬만 사용
- 오버샘플링이 "다수 복제"(X) → 소수를 늘림
- 구간화 "정보 손실 없음"(X) → 구간 내 차이 소실
- 상관 0 = 독립(X): 선형 관계 없음일 뿐 / 상관↑=인과(X)
- 스피어만 "정규 연속형만"(X) → 비모수, 정규성 불필요
- 박스플롯으로 최빈값 확인(X) — 5수 요약+이상값만
- 군집추출 "군집 내 동질·모든 군집"(X) → 내 이질·일부만
- 중심극한정리 "모집단 정규일 때만"(X) → 분포 무관, n≥30
- 신뢰구간 "모수가 있을 확률 95%"(X) → 확률의 주어는 반복된 구간
- p-value "H₀가 참일 확률"(X) → H₀ 참 가정 하 극단값 확률
- 포아송 분산 λ²(X) → λ / 이항 분산 np(X) → np(1−p)
- 표본↑이면 "α·β 동시 증가"(X) → α 고정 시 β↓·검정력↑
- 분리 처리 "이상값 폐기"(X) → 나눠서 각각 분석
- 온도=비율척도(X) → 구간척도(절대영점 없음)
- 민맥스: 분자·분모 **모두 최솟값 빼기** — (x−min)/(max−min)
- IQR 판정에서 음수라고 무조건 이상값 아님(하한과 비교)
