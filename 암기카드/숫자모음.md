## 계산 예제(함정 포함)

| 항목 | 값 | 각주 |
|---|---|---|
| IQR 계산 | Q1=10, Q3=30 → IQR=20, 하한 −20, 상한 60 | 65는 이상값, −10은 정상 |
| 민맥스 계산 | min20·max100에서 60 → 0.5 | (60−20)/(100−20) |
| 평균·중앙값 | 자료 3,4,5,6,22 → 평균 8, 중앙값 5 | 22 제거 시 평균 4.5 |
| 변동계수 | A: 20/100=0.2, B: 5/50=0.1 | A의 상대 산포가 더 큼 |
| 조건부확률 | P(A)=0.4, P(A∩B)=0.1 → P(B\|A)=0.25 | — |
| 이항분포 B(100,0.2) | E=20, V=16 | V=np(1−p)=100×0.2×0.8 |
| 베이즈 | A 60%·불량 2%, B 40%·불량 3% → P(A\|불량)=1/2 | 0.012/0.024 |
| 오즈 계산 | p=0.8 → 오즈 = 0.8/0.2 = 4 | 0.25(역수)·5(1/(1−p))가 함정 선지 |
| 연관분석 계산 | 10건 중 A 5·B 4·A∩B 2 → 지지도 0.2, 신뢰도 0.4, 향상도 1.0 | 향상도 1 = 독립 |
| 향상도 계산 2 | 신뢰도 0.6 ÷ P(김밥) 0.3 = 2 | 2배 → 양의 연관 |
| 기대빈도 계산 | (80×50)÷200 = 20 | (행 합×열 합)÷전체 |
| 불균형 데이터 반례 | 양성 1% → 전부 음성 예측 시 정확도 99% | 불균형에서 정확도 신뢰 불가 근거 |
