# 4과목 빅데이터 결과 해석 — 치트시트

## 1. 회귀 평가지표
| 지표 | 정의 한 줄 |
|---|---|
| MSE | 오차 제곱의 평균 (단위=종속변수 제곱) |
| RMSE | √MSE (단위=종속변수와 동일) |
| MAE | 오차 절댓값의 평균 (이상값 영향 MSE보다 작음) |
| MAPE | \|오차/실제값\| 백분율(%)의 평균 (단위 없음) |
| R² | SSR/SST = 1 − SSE/SST |
| 수정 R² | 변수 수 페널티 반영, 항상 R² 이하 |
- SST = SSR + SSE (전체 = 설명 + 오차)
- R² = 변수 넣을수록 감소 안 함 → 변수 수 다르면 수정 R²로 비교
- AIC·BIC = 작을수록 좋음, 둘 다 복잡도 벌점 有. BIC 벌점(ln n·k) > AIC 벌점(2k) → BIC가 더 단순 모형 선호
- 공식 판별: 제곱=MSE / √=RMSE / 절댓값=MAE / 실제값으로 나눔=MAPE

## 2. 분류 평가지표 (혼동행렬)
| 지표 | 공식 | 기준 |
|---|---|---|
| 정확도 | (TP+TN)/전체 | 전체 |
| 정밀도 | TP/(TP+FP) | 예측 양성 |
| 재현율=민감도=TPR | TP/(TP+FN) | 실제 양성 |
| 특이도 | TN/(TN+FP) | 실제 음성 |
| FPR | FP/(FP+TN) = 1 − 특이도 | 실제 음성 |
| F1 | 2PR/(P+R) 조화평균 | ≤ 산술평균 |
- ROC: x=FPR, y=TPR, 왼쪽 위로 붙을수록 좋음, 대각선=랜덤
- AUC: 0.5(랜덤) ~ 1(완벽), 클수록 좋음
- ROC 좌표 = (FPR, TPR) 순서 — "x축 먼저·FPR 먼저"
- 향상도(lift) = 모형 선별 집단 반응률 ÷ 전체 평균 반응률 (1이면 무의미)
- 지표 선택: 놓치면 큰일(진단)→재현율 / 오탐이 큰일(스팸)→정밀도 / 불균형→정확도 대신 F1

## 3. 교차검증·재추출
| 기법 | 정의 한 줄 |
|---|---|
| 홀드아웃 | 1회 분할, 분할 따라 결과 흔들림 |
| k-fold | k개 폴드, 각각 1회 평가, k회 평균 |
| LOOCV | k=n인 k-fold (LpOCV의 p=1) |
| LpOCV | ₙCₚ 조합 전부 반복 → 계산량 최대 |
| 부트스트랩 | 복원추출, 미포함 확률 ≈36.8%(1/e), 포함 ≈63.2% |
- 반복 횟수: 홀드아웃 1 < k-fold k < LOOCV n < LpOCV ₙCₚ
- 3분할: 학습(train)=학습 / 검증(validation)=하이퍼파라미터 튜닝 / 평가(test)=최종 성능

## 4. 적합도 검정 — 키워드 매칭
| 키워드 | 검정 |
|---|---|
| 관측도수 vs 기대도수 | 카이제곱 적합도 검정 |
| 누적분포함수(ECDF) 최대 거리 | K-S 검정 |
| 정규성 전용 | 샤피로-윌크 검정 |
| 분위수 그림(시각적) | Q-Q 플롯 |
- 카이제곱 용도 구분: 적합도(도수) / 독립성(범주형 두 변수)

## 5. 과적합·규제·신경망
- 훈련↑ 평가↓ = 과대적합 / 훈련↓ 평가↓ = 과소적합
- 과대적합 해결 = 데이터 증강·모형 단순화·규제·드롭아웃·조기 종료
- 과소적합 해결 = 모형 복잡화·변수 추가·학습 횟수 증가
| 규제 | 벌점 | 효과 |
|---|---|---|
| L1(라쏘) | 절댓값 합 | 계수 정확히 0 → 변수 선택·희소 |
| L2(릿지) | 제곱합 | 축소만, 0은 안 됨 |
| 엘라스틱넷 | L1+L2 | 절충 |
- 드롭아웃 = 학습 시 뉴런 무작위 제외 (예측 시엔 전부 사용)
- 배치 정규화 = 미니배치 단위 입력 정규화 → 학습 안정·가속
- 조기 종료 기준 = 검증 오차 증가 시점 (훈련 오차 아님)
- 기울기 소실 = 역전파 시 기울기→0, 시그모이드가 원인, ReLU가 완화
- 기울기 폭주 = 기울기 비정상 증가·발산

## 6. 경사하강법·옵티마이저·튜닝
| 방식 | 데이터 | 특성 |
|---|---|---|
| 배치 GD | 전체 | 안정·느림 |
| SGD | 1건 | 빠름·불안정(진동) |
| 미니배치 | 묶음 | 절충·실무 표준 |
- 학습률: 과대=발산·진동 / 과소=느린 수렴·지역해
- 옵티마이저 매칭: 모멘텀=관성·이전 방향 / AdaGrad=기울기 제곱 누적·학습률 감소→0 문제 / RMSProp=지수이동평균으로 AdaGrad 보완 / Adam=모멘텀+RMSProp
- 하이퍼파라미터(사람) = 학습률·에폭·배치 크기·은닉층 수·규제 강도 / 파라미터(학습) = 가중치·편향·회귀 계수
- 그리드 서치 = 전 조합 전수 탐색·조합 폭발 / 랜덤 서치 = 무작위 추출·넓은 공간에 효율
- 최종모형 선정 3요소 = 평가 데이터 성능 + 해석 가능성 + 운영(비즈니스) 적용성

## 7. 비즈니스 기여도 지표 — 단위로 구분
| 지표 | 정의 | 단위 |
|---|---|---|
| ROI | 순이익 ÷ 투자비 × 100 | 비율(%) |
| NPV | 미래 현금흐름 현재가치 − 투자비 | 금액 |
| IRR | NPV=0이 되는 할인율 | 할인율 |
| TCO | 도입~폐기 전 기간 총 비용 | 비용 |
| 회수 기간 | 투자비 ÷ 연간 순이익 | 기간 |
- 판단: NPV>0 채택 / IRR>요구수익률 채택 / 회수 기간 짧을수록 유리
- NPV는 할인율 따라 변함, IRR은 현금흐름이 결정(할인율 무관)
- 회수 기간법 한계 = 화폐의 시간가치 미반영
- 보고 원칙 = 기술 언어→비즈니스 언어, KPI·기대 효과 중심

## 8. 시각화 5유형 매칭
| 유형 | 대표 차트 |
|---|---|
| 시간 | 막대·선·영역·계단식 그래프 |
| 분포 | 파이·도넛·트리맵·누적 영역 |
| 관계 | 산점도·산점도 행렬·버블 차트·히스토그램 |
| 비교 | 히트맵·체르노프 페이스·스타 차트·평행 좌표 |
| 공간 | 등치지역도·도트맵·카토그램·버블 플롯맵 |
- 공간 구분: 색상 농도=등치지역도 / 점 밀도=도트맵 / 원 크기=버블 플롯맵 / 면적 왜곡=카토그램
- 비교 구분: 얼굴 요소=체르노프 / 방사형 축=스타 차트 / 평행 축+선=평행 좌표
- 시각화 절차: 구조화 → 시각화 → 시각표현 ("구·시·표")
- 인포그래픽 = 대중·쉬움·빠른 전달·흥미·스토리텔링

## 9. 분석 결과 활용
- 운영 사이클: 전개 → 모니터링(측정) → 저하 감지 → 리모델링
- 전개 = 검증 완료 모형의 운영 시스템 적용·배포 (배포하면 끝 아님)
- 모니터링 = 관찰(측정·추적·감지, 모형 그대로)
- 리모델링 = 조치(재학습·재개발, 모형 변경) — 데이터·환경 변화로 지속 저하 시
- 활용 시나리오 = 누가·언제·어떤 업무·어떻게 구체 정의, 기획 단계부터 고려

## 10. 함정 포인트
- R² 문제에 SSE 주어지면 "1에서 빼기" 필수 (SSE/SST 선지가 함정)
- F1: 산술평균 값이 선지에 있으면 함정 (조화평균으로 계산)
- 정밀도(예측 양성 기준) ↔ 특이도(실제 음성 기준) 정의 바꿔치기 단골
- FPR 문제: 특이도 값(1−빼기 누락)이 함정 선지
- ROC 좌표: (TPR, FPR)로 축 바꿔치기 함정
- 부트스트랩: 36.8%(미포함) ↔ 63.2%(포함) 숫자 바꿔치기
- LpOCV가 LOOCV보다 계산 적다? → 반대, ₙCₚ로 훨씬 많음
- BIC 벌점이 AIC보다 약하다? → 반대, BIC가 더 큼
- 불균형 1% 데이터: 전부 음성 예측해도 정확도 99% → 정확도 신뢰 불가
- 향상도: 차이(20−5)나 역수(5/20)가 함정, 나눗셈(20/5)이 정답
- L2가 계수를 0으로 만든다? → L1의 특징
- 조기 종료 기준 "훈련 오차"? → 검증 오차
- Adam = AdaGrad+배치정규화? → 모멘텀+RMSProp
- 시그모이드가 기울기 소실 해결? → 원인임, 해결은 ReLU
- ROI ↔ IRR 정의 바꿔치기 ("NPV=0 할인율"은 무조건 IRR)
- ROI 분모에 투자+이익 합계 넣는 실수 (분모=투자비만)
- 회수 기간 길수록 위험 낮다? → 짧을수록 유리
- 히트맵은 비교 시각화 (공간 아님) / 버블 "차트"=관계, 버블 "플롯맵"=공간
- 트리맵 = 분포 시각화 (비교 아님) / 히스토그램 = 관계 시각화(KDATA 기준)
- 카토그램 ↔ 등치지역도 특징 바꿔치기 (면적 왜곡=카토그램)
- 드롭아웃은 예측 시에도 뉴런 제외? → 학습 시에만
- "항상·무조건" 들어간 선지는 함정 확률 높음
- 활용 시나리오 수립 시점 "폐기 시점"? → 기획 단계부터
- 모니터링 감지 후 "그대로 사용"? → 리모델링 검토가 정답
