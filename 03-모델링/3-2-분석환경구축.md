### Q3-009 [난이도: 하] [태그: 3과목/분석모형설계/데이터분할]

분석가 A는 확보한 전체 데이터를 60:20:20의 비율로 세 부분으로 나누어 모델링을 진행하려 한다. 이 중 모델의 하이퍼파라미터(hyperparameter)를 튜닝하고 과대적합(overfitting) 발생 여부를 확인하는 데 사용하는 데이터는?

① 훈련 데이터(training data)
② 검증 데이터(validation data)
③ 평가 데이터(test data)
④ 원시 데이터(raw data)

<details><summary>정답 및 해설</summary>

**정답: ②**

- **①** 훈련 데이터: 모델의 파라미터(가중치)를 **학습**시키는 데 사용. 튜닝·과적합 확인 용도가 아님.
- **②** 검증 데이터: 학습 중간에 성능을 점검하며 **하이퍼파라미터 튜닝 + 과대적합 여부 확인**에 사용. ← 정답
- **③** 평가 데이터: 학습·튜닝이 모두 끝난 모델의 **최종 일반화 성능 측정**에만 사용.
- **④** 원시 데이터: 분할 이전의 가공되지 않은 수집 데이터를 가리키는 말로, 분할 3종에 속하지 않음.

**출제 포인트:** 데이터 3분할 역할 = **훈련(학습) / 검증(튜닝·과적합 확인) / 평가(최종 성능)**. "튜닝"이 보이면 무조건 검증 데이터.

**근거:** 검증 데이터(validation data)는 훈련 데이터로 학습된 모델의 하이퍼파라미터를 조정하고 과대적합 여부를 확인하기 위해 학습 과정에서 사용하는 데이터다.
</details>

### Q3-010 [난이도: 중] [태그: 3과목/분석모형설계/분석도구]

빅데이터 분석 환경으로서 R과 Python(파이썬)에 대한 설명으로 가장 적절한 것은?

① R은 통계 분석에 특화된 오픈소스 언어이며, Python은 범용 언어로 웹 개발 등 다른 시스템과의 연동·확장에 유리하다.
② Python의 pandas는 R의 CRAN에 해당하는 것으로, 패키지를 배포·설치하는 중앙 저장소 역할을 한다.
③ R은 데이터를 메모리에 올려 처리하는 인메모리(in-memory) 방식이 아니므로, 대용량 데이터 처리 시 메모리 용량의 제약을 받지 않는다.
④ R은 웹 개발 등 여러 분야에서 쓰이도록 설계된 범용 언어이고, Python은 통계학자를 위해 개발된 통계 전용 언어이다.

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** R = 통계·시각화 특화, Python = 범용 언어(웹·시스템 연동·확장성). 두 도구의 표준적 비교. ← 정답
- **②** pandas는 데이터 분석용 **라이브러리**다. CRAN에 대응하는 Python의 패키지 **저장소**는 PyPI(Python Package Index). 라이브러리와 저장소 개념을 바꿔치기한 틀린 설명.
- **③** R은 기본적으로 데이터를 메모리에 적재해 처리하는 **인메모리 방식**이므로, 메모리 용량이 대용량 처리의 제약이 된다. 두 사실을 모두 뒤집은 틀린 설명.
- **④** R과 Python의 성격을 **서로 바꿔치기**한 서술. 통계학자 기반의 통계 특화 언어가 R, 범용 언어가 Python이다. 틀린 설명.

**출제 포인트:** R = 통계 특화 + 인메모리 처리 + **저장소 CRAN** / Python = 범용 + **저장소 PyPI** + 라이브러리(pandas, scikit-learn 등). "특화 vs 범용", "저장소 vs 라이브러리"의 짝을 바꿔치기하는 선지에 주의.

**근거:** R은 통계 분석과 시각화에 특화된 오픈소스 언어이고, Python은 범용 프로그래밍 언어로서 라이브러리를 통해 데이터 분석을 지원하며 다른 시스템과의 연동성이 높다.
</details>

### Q3-011 [난이도: 중] [태그: 3과목/분석모형설계/데이터분할]

훈련·검증·평가 데이터의 역할에 대한 설명으로 옳지 <u>않은</u> 것은?

① 훈련 데이터는 모델의 파라미터(가중치)를 학습시키는 데 사용된다.
② 검증 데이터는 하이퍼파라미터 튜닝과 과대적합(overfitting) 발생 여부 확인에 사용된다.
③ 평가 데이터는 학습과 튜닝에 관여하지 않은 데이터로, 완성된 모델의 최종 성능 측정에 사용된다.
④ 평가 데이터로 하이퍼파라미터를 조정한 뒤 같은 평가 데이터로 최종 성능을 측정하면 일반화 성능을 객관적으로 평가할 수 있다.

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 옳은 설명. 훈련 데이터의 역할은 모델 학습(파라미터 추정) 그 자체.
- **②** 옳은 설명. 튜닝·과적합 확인은 검증 데이터의 고유 역할.
- **③** 옳은 설명. 평가 데이터는 모델 구축 과정에 한 번도 노출되지 않아야 최종 성능 측정이 유효하다.
- **④** 하이퍼파라미터 튜닝은 **검증 데이터**의 역할이다. 평가 데이터를 튜닝에 쓰면 모델이 그 데이터에 맞춰지므로, 같은 데이터로 잰 성능은 일반화 성능을 **과대평가**하게 된다. ← 정답

**출제 포인트:** 검증 데이터(튜닝) ↔ 평가 데이터(최종 측정)의 역할 바꿔치기가 단골 함정. "평가 데이터는 학습·튜닝 어디에도 쓰지 않는다"만 기억하면 걸러진다.

**근거:** 평가 데이터(test data)는 모델의 학습과 하이퍼파라미터 튜닝 어디에도 사용되지 않은 데이터로, 최종 모델의 일반화 성능을 측정하는 데만 사용하는 데이터다.
</details>

### Q3-012 [난이도: 상] [태그: 3과목/분석모형설계/분석도구선정]

빅데이터 분석 도구의 선정에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. R과 Python은 오픈소스(open source) 언어로 라이선스 비용 없이 사용할 수 있으며, 커뮤니티가 개발한 패키지를 통해 기능을 확장한다.
- ㄴ. SAS와 SPSS는 라이선스를 구매하여 사용하는 상용(commercial) 분석 도구로, 공급 업체(벤더)의 공식 기술 지원을 받을 수 있다.
- ㄷ. SPSS는 메뉴 선택 방식의 그래픽 사용자 인터페이스(GUI)를 제공하여 프로그래밍에 익숙하지 않은 사용자도 비교적 쉽게 사용할 수 있다.
- ㄹ. 상용 분석 도구는 오픈소스 도구보다 최신 분석 기법이 더 신속하게 반영되는 것이 일반적이다.

① ㄱ, ㄴ  ② ㄴ, ㄷ, ㄹ  ③ ㄱ, ㄴ, ㄷ  ④ ㄱ, ㄷ, ㄹ

<details><summary>정답 및 해설</summary>

**정답: ③**

- **ㄱ (O)** R·Python = **오픈소스·무료** + 커뮤니티 기반 패키지 생태계(CRAN·PyPI)로 기능 확장.
- **ㄴ (O)** SAS·SPSS = **상용 라이선스** 도구로, 벤더의 공식 기술 지원·유지보수를 받을 수 있는 것이 장점.
- **ㄷ (O)** SPSS는 메뉴(GUI) 방식 조작이 특징이라 코딩 부담이 적어 비전공자 접근성이 높다.
- **ㄹ (X)** 반대다. **오픈소스 도구는 전 세계 커뮤니티의 기여로 최신 분석 기법이 패키지 형태로 빠르게 반영**되는 것이 장점이고, 상용 도구는 벤더의 정식 배포 절차를 거치므로 상대적으로 반영이 느린 편이다.

따라서 옳은 것은 ㄱ, ㄴ, ㄷ → **③**. (①은 옳은 ㄷ을 누락, ②·④는 틀린 ㄹ을 포함)

**출제 포인트:** 오픈소스(R·Python) = 무료 + 커뮤니티 패키지 + 최신 기법 반영 빠름 + 공식 기술 지원은 없음 / 상용(SAS·SPSS) = 라이선스 비용 + 벤더 기술 지원 + (SPSS) GUI 친화. 두 진영의 장단점을 서로 바꿔치기한 선지가 단골 함정.

**근거:** R과 Python은 오픈소스 기반의 무료 분석 도구로 커뮤니티 패키지를 통해 최신 기법이 빠르게 반영되고, SAS와 SPSS는 벤더의 공식 기술 지원이 제공되는 상용 분석 도구이며, SPSS는 메뉴 방식의 GUI로 사용 편의성이 높다.
</details>
