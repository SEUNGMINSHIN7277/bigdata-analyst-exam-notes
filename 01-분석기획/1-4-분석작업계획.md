### Q1-037 [난이도: 하] [태그: 1과목/데이터분석계획/WBS]

프로젝트의 전체 작업을 계층적으로 세분화하여 관리 가능한 최소 단위의 작업으로 나누고, 이를 기준으로 일정·산출물·담당자를 관리할 수 있게 하는 것은?

① WBS(작업 분할 구조)
② 간트 차트(Gantt chart)
③ 분석 목표 정의서
④ 위험 관리 대장

<details><summary>정답 및 해설</summary>

**정답: ①**

- **①** WBS(Work Breakdown Structure): 전체 작업을 계층적으로 **분할**해 최소 관리 단위로 만든 구조. 일정·산출물·담당자 관리의 기준. ← 정답
- **②** 간트 차트: 작업별 일정을 **막대(bar) 형태로 시각화**하는 도구. 작업을 분할하는 구조가 아니라 분할된 작업의 일정을 표현하는 수단.
- **③** 분석 목표 정의서: 분석 목표·원천 데이터·평가 기준을 정의한 **문서**. 작업 분할·일정 관리 도구가 아님.
- **④** 위험 관리 대장: 프로젝트 위험 요소를 식별·기록·추적하는 문서. 작업 분할과 무관.

**출제 포인트:** "계층적 세분화 + 최소 관리 단위"가 보이면 WBS. 간트 차트는 '일정 시각화', WBS는 '작업 분할'로 역할을 구분해 둘 것.

**근거:** WBS(작업 분할 구조, Work Breakdown Structure)는 프로젝트의 작업을 계층적으로 분할하여 관리 가능한 최소 단위로 정의하고 일정·산출물 관리의 기준으로 삼는 구조다.
</details>

### Q1-038 [난이도: 중] [태그: 1과목/데이터분석계획/분석목표정의서]

데이터 분석 목표 정의서의 구성요소에 해당하지 <u>않는</u> 것은?

① 원천 데이터 조사
② 분석 방안 및 적용 가능성 판단
③ 성과 평가 기준
④ 분석 모델의 최적 하이퍼파라미터(hyperparameter) 설정값

<details><summary>정답 및 해설</summary>

**정답: ④**

- **①** 필요 데이터의 존재 여부·수집 난이도·용량 등 원천 데이터 정보를 조사 → 구성요소 맞음.
- **②** 분석 목표를 달성할 분석 방안과 그 적용 가능성(현실성)을 판단 → 구성요소 맞음.
- **③** 정성적·정량적 평가 기준을 사전에 정의 → 구성요소 맞음.
- **④** 하이퍼파라미터 설정값은 **모델링(분석 수행) 단계**에서 실험으로 결정하는 사항. 기획 단계 문서인 목표 정의서의 구성요소가 아님. ← 정답

**출제 포인트:** 분석 목표 정의서 3요소 = **원천 데이터 조사 / 분석 방안·적용 가능성 판단 / 성과 평가 기준**. "원·방·평"으로 암기. 모델링 단계의 세부 사항(파라미터, 알고리즘 튜닝)이 섞여 나오면 오답. ※ 교재별 표기 차이 있음 — 구성요소의 명칭·세분화 수준은 교재마다 다르게 제시될 수 있다.

**근거:** 분석 목표 정의서는 원천 데이터 조사, 분석 방안 및 적용 가능성 판단, 성과 평가 기준을 담아 분석 목표를 구체화하는 기획 단계 문서다.
</details>

### Q1-039 [난이도: 중] [태그: 1과목/데이터분석계획/데이터확보계획]

데이터 확보 계획 수립 절차를 순서대로 바르게 나열한 것은?

- ㄱ. 요구사항 도출 (필요 데이터·기술 지원 등)
- ㄴ. 예산안 수립
- ㄷ. 목표 정의 (성과 목표·성과 지표 설정)
- ㄹ. 계획 수립 (인력·일정·업무·예산 반영 계획서 작성)

① ㄷ → ㄴ → ㄱ → ㄹ
② ㄷ → ㄱ → ㄴ → ㄹ
③ ㄱ → ㄷ → ㄴ → ㄹ
④ ㄷ → ㄱ → ㄹ → ㄴ

<details><summary>정답 및 해설</summary>

**정답: ②**

- **②** 목표 정의(ㄷ) → 요구사항 도출(ㄱ) → 예산안 수립(ㄴ) → 계획 수립(ㄹ). ← 정답
- **①** 요구사항을 모르는 상태에서 예산부터 세울 수 없다. 예산은 요구사항 도출 **뒤**.
- **③** 목표가 정의되어야 그 목표 달성에 필요한 요구사항을 도출할 수 있다. 목표 정의가 **첫 단계**.
- **④** 계획 수립은 예산까지 반영해 작성하는 **마지막 단계**. 예산안 수립보다 앞설 수 없다.

**출제 포인트:** 데이터 확보 계획 절차 = **목표 → 요구 → 예산 → 계획**. "목·요·예·계"로 암기. 논리 흐름(목표가 있어야 요구가 나오고, 요구가 있어야 예산이 나온다)을 이해하면 나열 순서를 외우지 않아도 복원 가능.

**근거:** 데이터 확보 계획은 성과 목표·지표를 정의한 뒤 요구사항을 도출하고, 예산안을 수립한 다음 인력·일정·업무·예산을 반영한 계획서를 작성하는 순서로 수립한다.
</details>

### Q1-040 [난이도: 상] [태그: 1과목/데이터분석계획/작업분할일정계획]

데이터 분석 프로젝트의 WBS(작업 분할 구조) 단계별 작업과 일정 계획에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. 데이터 분석과제 정의 단계에서는 분석 목표 정의서를 기준으로 프로젝트 전체 일정에 맞춰 사전 준비를 한다.
- ㄴ. 데이터 준비 및 탐색 단계에서는 데이터 처리 담당자와 데이터 분석가의 역할을 구분하여 세부 일정을 수립한다.
- ㄷ. 데이터 분석 모델링 및 검증 단계는 데이터 준비 및 탐색 단계보다 먼저 수행한다.
- ㄹ. 산출물 정리 단계에서는 분석 결과와 산출물·프로그램(소스 코드)을 정리하여 프로젝트를 마무리한다.

① ㄱ, ㄴ  ② ㄴ, ㄷ, ㄹ  ③ ㄱ, ㄴ, ㄹ  ④ ㄱ, ㄷ, ㄹ

<details><summary>정답 및 해설</summary>

**정답: ③**

- **ㄱ (O)** 1단계(데이터 분석과제 정의): 분석 목표 정의서 기준으로 전체 일정에 맞춘 사전 준비.
- **ㄴ (O)** 2단계(데이터 준비 및 탐색): 데이터 처리와 분석의 **역할을 구분**해 세부 일정 수립.
- **ㄷ (X)** 순서가 반대. 데이터가 준비·탐색된 **뒤에** 모델링 및 검증(3단계)을 수행한다.
- **ㄹ (O)** 4단계(산출물 정리): 분석 결과·산출물·프로그램을 정리하며 프로젝트 종료.

따라서 옳은 것은 ㄱ, ㄴ, ㄹ → **③**. (①은 옳은 ㄹ을 누락, ②·④는 틀린 ㄷ을 포함)

**출제 포인트:** 데이터 분석 WBS 4단계 = **과제 정의 → 데이터 준비·탐색 → 분석 모델링·검증 → 산출물 정리**. "정·준·모·산"으로 암기. 단계 순서를 뒤집는 선지가 단골 함정. ※ 교재별 표기 차이 있음 — 단계 명칭은 교재에 따라 다소 다르게 표기될 수 있다.

**근거:** 데이터 분석 프로젝트의 WBS는 데이터 분석과제 정의, 데이터 준비 및 탐색, 데이터 분석 모델링 및 검증, 산출물 정리의 4단계로 작업을 분할하여 일정을 계획한다.
</details>
