## 1과목 빅데이터 분석 기획 (1~20번)

**1.** 가트너(Gartner)가 제시한 빅데이터의 기본 3V에 해당하지 <u>않는</u> 것은?

① 규모(Volume)  ② 속도(Velocity)  ③ 다양성(Variety)  ④ 신뢰성(Veracity)

**2.** 데이터 유형에 대한 설명으로 옳지 <u>않은</u> 것은?

① 정형 데이터는 미리 정의된 스키마에 따라 고정된 필드에 저장된다.
② 반정형 데이터는 스키마·메타데이터 정보를 데이터 내부에 포함하며 XML, JSON이 대표적이다.
③ 비정형 데이터는 정해진 구조가 없으며 동영상, 음성, 이미지 등이 해당한다.
④ 반정형 데이터는 메타데이터를 갖지 않으므로 구조 파악이 불가능하다.

**3.** 분석 전담 조직의 인력을 현업 부서에 직접 배치하여 분석 업무를 수행하게 하는 빅데이터 분석 조직 구조는?

① 집중 구조  ② 기능 구조  ③ 분산 구조  ④ 계층 구조

**4.** 빅데이터의 특성(V)에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. 기본 3V는 규모(Volume), 속도(Velocity), 다양성(Variety)이다.
- ㄴ. 가치(Value)는 기본 3V에 포함되는 특성이다.
- ㄷ. 신뢰성(Veracity)은 수집한 데이터의 품질·정확성과 관련된 특성이다.
- ㄹ. 휘발성(Volatility)은 데이터가 의미를 갖고 저장·활용될 수 있는 기간과 관련된 특성이다.

① ㄱ, ㄷ, ㄹ  ② ㄱ, ㄴ, ㄷ  ③ ㄴ, ㄷ, ㄹ  ④ ㄱ, ㄹ

**5.** 분산 환경에서 여러 서버가 공유하는 설정 정보의 유지·관리, 서버 간 동기화, 리더 선출(leader election) 등 분산 애플리케이션의 코디네이션(coordination)을 담당하는 하둡 에코시스템 컴포넌트는?

① Oozie  ② Zookeeper  ③ Avro  ④ Hive

**6.** 클라우드 컴퓨팅 서비스 모델(IaaS/PaaS/SaaS)에 대한 설명으로 옳은 것은?

① IaaS는 응용 소프트웨어까지 완제품 형태로 제공한다.
② PaaS는 애플리케이션 개발·실행 환경을 제공하므로 이용자는 인프라를 직접 관리하지 않고 애플리케이션 개발·배포에 집중할 수 있다.
③ SaaS는 서버·스토리지·네트워크 등 인프라 자원만을 가상화하여 제공한다.
④ IaaS 이용자는 가상 서버의 운영체제(OS)를 직접 선택하거나 관리할 수 없다.

**7.** 개별 데이터 값을 데이터의 총합 또는 평균값으로 대체하여 개별 값이 드러나지 않도록 하는 비식별화(데이터 비식별 조치) 기법은?

① 총계처리  ② 가명처리  ③ 데이터 범주화  ④ 데이터 마스킹

**8.** 개인정보 보호법상 개인정보 처리(수집·이용)의 기본 원칙에 대한 설명으로 옳지 <u>않은</u> 것은?

① 적법하게 수집한 개인정보는 당초 수집 목적과 무관한 용도로도 제한 없이 이용할 수 있다.
② 개인정보의 처리 목적을 명확하게 하고, 그 목적에 필요한 최소한의 범위에서 수집하여야 한다.
③ 익명 처리로도 목적을 달성할 수 있는 경우에는 익명 처리를 우선하고, 익명 처리가 곤란하면 가명 처리에 의하도록 한다.
④ 처리 목적에 필요한 범위에서 개인정보의 정확성·완전성·최신성이 보장되도록 하여야 한다.

**9.** 분석 방법론과 각 방법론을 구성하는 단계 수의 연결이 모두 옳은 것은?

① KDD 5단계 — CRISP-DM 5단계 — SEMMA 6단계
② KDD 5단계 — CRISP-DM 6단계 — SEMMA 5단계
③ KDD 6단계 — CRISP-DM 5단계 — SEMMA 5단계
④ KDD 4단계 — CRISP-DM 6단계 — SEMMA 6단계

**10.** 다음 중 CRISP-DM 방법론의 6단계에 해당하지 <u>않는</u> 것은?

① 업무 이해(Business Understanding)
② 데이터 준비(Data Preparation)
③ 전개(Deployment)
④ 데이터 변환(Transformation)

**11.** 분석 과제 발굴의 상향식(bottom-up) 접근과 관련된 설명으로 옳지 <u>않은</u> 것은?

① 상향식 접근은 문제 정의 자체가 어려운 경우 데이터를 기반으로 통찰(insight)을 도출하는 방식이다.
② 프로토타이핑(prototyping) 접근은 일단 분석을 시도하고 결과를 확인하며 반복적으로 개선하는 시행착오 방식이다.
③ 디자인 씽킹(design thinking)은 상향식의 발산(diverge) 단계와 하향식의 수렴(converge) 단계를 반복하여 최적의 방안을 도출한다.
④ 상향식 접근은 문제가 명확히 주어진 상태에서 해법을 찾아가는 전통적 분석 과제 발굴 방식이다.

**12.** 빅데이터 분석 기획 단계에서 1차적으로 고려해야 할 사항으로 가장 적절한 것은?

① 분석 모형에 적용할 알고리즘의 하이퍼파라미터 튜닝 전략 수립
② 분석 결과 대시보드의 화면 배치와 차트 종류 확정
③ 분석 서버의 CPU 코어 수와 메모리 용량 확정
④ 활용 가능한 데이터의 존재 여부·유형 확인과 장애요소에 대한 사전계획 수립

**13.** 데이터 확보 계획 수립 절차를 순서대로 바르게 나열한 것은?

- ㄱ. 요구사항 도출 (필요 데이터·기술 지원 등)
- ㄴ. 예산안 수립
- ㄷ. 목표 정의 (성과 목표·성과 지표 설정)
- ㄹ. 계획 수립 (인력·일정·업무·예산 반영 계획서 작성)

① ㄷ → ㄴ → ㄱ → ㄹ
② ㄷ → ㄱ → ㄴ → ㄹ
③ ㄱ → ㄷ → ㄴ → ㄹ
④ ㄷ → ㄱ → ㄹ → ㄴ

**14.** 데이터 분석 프로젝트의 WBS(작업 분할 구조) 단계별 작업과 일정 계획에 대한 설명 중 옳은 것만 모두 고른 것은?

- ㄱ. 데이터 분석과제 정의 단계에서는 분석 목표 정의서를 기준으로 프로젝트 전체 일정에 맞춰 사전 준비를 한다.
- ㄴ. 데이터 준비 및 탐색 단계에서는 데이터 처리 담당자와 데이터 분석가의 역할을 구분하여 세부 일정을 수립한다.
- ㄷ. 데이터 분석 모델링 및 검증 단계는 데이터 준비 및 탐색 단계보다 먼저 수행한다.
- ㄹ. 산출물 정리 단계에서는 분석 결과와 산출물·프로그램(소스 코드)을 정리하여 프로젝트를 마무리한다.

① ㄱ, ㄴ  ② ㄴ, ㄷ, ㄹ  ③ ㄱ, ㄴ, ㄹ  ④ ㄱ, ㄷ, ㄹ

**15.** 서버-클라이언트 방식으로 동작하며, 수집 대상 시스템과 1:1로 연결하여 파일과 디렉터리를 동기화(미러링)하는 데 사용되는 데이터 수집 기술은?

② FTP
③ RSS
④ Open API

**16.** 이벤트(event)와 에이전트(agent)를 기반으로 하며, 소스(source)–채널(channel)–싱크(sink) 구조로 대용량 로그 데이터를 안정적으로 수집하는 기술은?

② 로그스태시(Logstash)

**17.** 파일 전송 프로토콜 FTP(File Transfer Protocol)에 대한 설명으로 옳은 것은?

① UDP 기반 프로토콜이므로 전송의 신뢰성을 보장하지 않는다.
② 능동(active) 모드에서는 클라이언트가 서버의 데이터 포트에 먼저 접속하여 데이터 연결을 생성한다.
③ 수동(passive) 모드에서는 서버가 알려 준 임의의 포트로 클라이언트가 접속하여 데이터 연결을 생성한다.
④ 제어(명령) 연결에는 기본적으로 20번 포트가 사용된다.

**18.** 문서 기반(Document Store) NoSQL 데이터베이스의 대표 제품은?

① Redis  ② MongoDB  ③ Neo4j  ④ HBase

**19.** 하둡 분산 파일 시스템(HDFS)에 대한 설명으로 옳지 <u>않은</u> 것은?

① 네임노드(NameNode)는 파일 시스템의 메타데이터를 관리한다.
② 데이터노드(DataNode)가 메타데이터를 저장하고, 네임노드가 실제 데이터 블록을 저장한다.
③ 파일은 블록(block) 단위로 분할되어 여러 데이터노드에 분산 저장된다.
④ 블록은 기본적으로 여러 노드에 복제 저장되어 일부 노드 장애 시에도 데이터를 보존할 수 있다.

**20.** 데이터 저장소에 대한 설명으로 옳지 <u>않은</u> 것은?

① 데이터 레이크는 원시(raw) 데이터를 원래 형식 그대로 저장하며, 스키마를 읽는 시점에 적용한다(Schema-on-Read).
② ODS는 데이터 웨어하우스 적재 전에 운영계 데이터를 임시로 통합·저장하는 저장소다.
③ 데이터 마트는 정형·비정형 원시 데이터를 가공 없이 그대로 축적한다는 점에서 데이터 레이크와 성격이 같다.
④ 데이터 웨어하우스는 정제·통합된 정형 데이터를 적재 시점에 스키마에 맞춰 저장한다(Schema-on-Write).

## 2과목 빅데이터 탐색 (21~40번)

**21.** 소득 설문조사에서 고소득자일수록 자신의 소득 노출을 꺼려 소득 문항에 응답하지 않는 경향이 확인되었다. 이 소득 변수의 결측 유형은?

① 완전 무작위 결측(MCAR)
② 무작위 결측(MAR)
③ 표본 추출 오류
④ 비무작위 결측(MNAR)

**22.** 관측치 주변의 국소 밀도(local density)를 k-최근접 이웃들의 밀도와 비교하여, 이웃들에 비해 상대적으로 밀도가 낮은 곳에 있는 관측치를 이상값으로 판별하는 기법은?

① 아이솔레이션 포레스트(iForest, Isolation Forest)
② 국소 이상치 요인(LOF, Local Outlier Factor)
③ ESD(Extreme Studentized Deviate)
④ 사분위수 범위(IQR) 규칙

**23.** 건강 설문에서 성별에 따라 체중 문항의 무응답률이 다르게 나타났으나, 같은 성별 집단 안에서는 무응답이 체중 값 자체와는 무관하게 발생했다. 이 체중 변수의 결측 유형은?

① 완전 무작위 결측(MCAR)
② 무작위 결측(MAR)
③ 비무작위 결측(MNAR)
④ 잡음(noise)

**24.** 결측값 대치법에 대한 설명으로 옳지 <u>않은</u> 것은?

① 핫덱(hot-deck) 대치는 현재 진행 중인 같은 조사(데이터셋) 안에서 유사한 특성을 가진 다른 응답자의 값을 가져와 대치한다.
② 콜드덱(cold-deck) 대치는 과거 조사나 외부 자료 등 다른 출처의 값을 가져와 대치한다.
③ 평균 대치법은 결측값을 평균으로 채우므로 자료의 분산이 실제보다 커지는 문제가 있다.
④ 확률적 회귀 대치는 회귀 예측값에 오차항을 더해 대치함으로써 단순 회귀 대치의 변동성 과소평가를 보완한다.

**25.** 모델 학습 없이 상관계수, 카이제곱 통계량, 정보 이득(information gain) 등 통계적 측도만으로 변수의 유의성을 평가하여 선택하는 변수 선택 방식은?

① 래퍼(wrapper) 기법  ② 필터(filter) 기법  ③ 임베디드(embedded) 기법  ④ 배깅(bagging) 기법

**26.** 파생변수(derived variable)에 대한 설명으로 가장 적절한 것은?

① 여러 관측치를 합계·평균 등으로 집계한 변수로, 재활용성이 높다.
② 원본 변수를 다른 이름으로 그대로 복사해 저장한 변수다.
③ 누구에게나 의미가 같은 객관적 변수이므로 별도의 정당성 검토가 필요 없다.
④ 분석자가 특정 목적에 따라 조건·함수 등 논리적 가공으로 새로 정의한 변수로, 주관적일 수 있어 타당한 근거가 필요하다.

**27.** 변수 선택의 임베디드(embedded) 기법에 해당하는 것으로만 묶인 것은?

① 라쏘(LASSO), 릿지(Ridge), 엘라스틱넷(Elastic Net)
② 전진 선택법, 후진 제거법, 단계적 방법
③ 상관계수, 카이제곱 검정, 정보 이득
④ 주성분분석(PCA), 요인분석, 다차원척도법(MDS)

**28.** 클래스(범주) 정보를 이용하여 클래스 간 분산은 최대화하고 클래스 내 분산은 최소화하는 축으로 데이터를 사영(projection)하는 차원축소 기법은?

① 주성분분석(PCA)  ② 선형판별분석(LDA)  ③ 다차원척도법(MDS)  ④ 특이값분해(SVD)

**29.** 분석 변수 처리에 대한 설명 중 옳은 것만 모두 고른 것은?
